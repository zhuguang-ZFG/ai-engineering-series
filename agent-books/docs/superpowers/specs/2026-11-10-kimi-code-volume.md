## 主线

书名《Kimi Code：从插件到审查助手》。从澄明库存项目的两处边界错误出发，搭建可复用的审查工作流：先复现问题，再组织 Skill、受限 Agent、插件命令、Hook 和 MCP，最后接入 ACP 客户端并恢复中断的审查。

前言、18 章、附录 A–D。每章有完整解释、可定位的钉版来源和具体操作；不能用提纲、重复提醒或泛化结论填充篇幅。命令标明运行目录，示例文件随书提供，模型练习与离线验证分别记录。
