范围：`ch01`–`ch15`（15 章 × 双语 = 30 文件）。front 与 apxa–d 不动。

## 2. 铁律

1. **双语行级同步**：zh 加几行，en 在对应位置加几行；en ch14 保留既有 +1 漂移（从 ~L379 起）。
2. **隐喻纪律**：每章钩子必须复用该章已建立的隐喻（车马/驿传/腰牌/账房…，见 notes.json 该章条目与章内比喻），**不得引入新隐喻体系**。禁 "揭示了/展现了/让我们/不难发现" 等 AI 腔。
3. **信息零增零漏**：钩子与回收只做已有内容的记忆化重述，不引入新事实、新数字、新术语；数字/术语/归因与正文一致。
4. **锚点纪律**：R3 是**行数增加轮**。每处插入后跑 `scripts/shift_anchors.py --after N --delta M`（先 dry-run，再 `--write`），registry 只涉及 glosses.json 与 manifest.json。notes.json / reading-paths.json 无行引用，不受影响。
5. **quality bar**：钩子 ≤40 汉字，具体、有画面、复用该章中心比喻；回收三句"由深回浅"——①本章最深的那件事 ②它为什么重要 ③一句能带走的判断。

## 3. 三处插入的统一规格

每章净增 6 行（zh/en 各 6；A/B/C 各 +2）：

| # | 内容 | 位置 | 行数变化 |
|---|---|---|---|
| A | 开门一句话钩子 | H1 行之后第一个元素之前：`> **开门一句话：**……`（en：`> **In one line:** ...`） | +2（引块行 + 空行） |
| B | 难度定位 | 学习目标块结束的空行之后：`**难度定位：**……`（en：`**Difficulty:** ...`），行后保留空行（紧邻 `---` 会被 CommonMark 当 setext 标题），复用 起步/主干/进阶 词表，说明哪些节初读可跳过 | +2（难度行 + 分隔空行） |
| C | 三句话带走 | `## 关键要点` 列表末项之后（该节是全章最后一节）：`> **三句话带走：**①……②……③……`（en：`> **Three sentences to keep:** ...`） | +2 |

锚点平移顺序（每章文件内自上而下依次执行，脚本会基于已平移的 registry 继续）：
1. 插入 A 后：`shift_anchors.py <zh 文件> <en 文件> --after <H1 行号> --delta 2`（dry-run 先行）。
2. 插入 B 后：`--after <B 所在行> --delta 2`。
3. 插入 C 后：`--after <C 所在行> --delta 2`（关键要点在文件末尾，通常 0 引用，dry-run 确认）。

zh 与 en 的插入行号不同（en ch14 有漂移）时**分开调用**，各自 --after。

## 4. 工人执行契约（每章一个循环）

1. 读该章 zh 全文 + en 对应章，对照 `notes.json` 该章隐喻条目。
2. 起草 A/B/C 双语六件内容；自查铁律 2/3/5。
3. 按 §3 顺序插入并平移锚点（每步 dry-run → write）。
4. 跑 `python yuyu-book/build.py --check`（只读、秒级）——**必须绿**才能进入下一章；红了先修（通常是锚点漏移）。
5. 汇报：每章 before/after 行数、六件内容全文、shift 命令清单。
