New terms in this chapter22

Every dashed term in the text is listed here; Appendix D covers the rest.

  • Agent Harnessthe program wrapped around the model: it takes the request, hands out tools, checks permission, brings back the answer
  • context windowhow much text the model can hold in mind at once; new material pushes the oldest material off the edge
  • streaminghandle bits as they land; here, the model's reply arrives word by word
  • blockingstuck waiting in place, unable to do anything else meanwhile
  • callbackyou hand over what to do next and get called when it finishes
  • Promisea receipt for a value that arrives later; it settles exactly once
  • sub-agenta second agent spawned for one small task with its own message history, reporting back only the answer
  • immutabilitynever overwrite data; copy it, change the copy, keep the original
  • Main Loopask the model, run the tools it asks for, ask again, until the task is finished
  • permission modethe rule for who approves each action, and how often the agent has to stop and ask
  • async generatora function that hands out results one piece at a time and can pause between pieces
  • system promptthe standing instruction sent on top of every request: who it is, what it may do, what it must obey
  • permission pipelineseveral gates every tool call must pass in order; if any gate says stop, it stops right there
  • tool resultwhat an action hands back -- file text, command output or an error -- fed into the chat as a new message
  • concurrencyseveral tasks in flight at once, competing for shared things
  • event streamhappenings come out one by one and are handled as they arrive
  • event emitteran object that broadcasts happenings to whoever subscribed
  • sandboxan enclosed area where code plays without touching anything outside
  • Fork patterncopying the conversation as it stands into several branches so parallel jobs share one starting point
  • skilla written-down procedure the model can be handed and follow, instead of being re-taught every time
  • MCP serveran outside program that speaks one shared protocol, handing the agent extra tools and data
  • race conditiontwo paths touch the same data at once; the outcome depends on timing
