# Omp 钉版策略

写作钉为 `omp/18.15.0`，本机验证钉为 `omp/18.16.0`（Windows、Bun 全局安装）。
两者分别回答「这段文字依据哪版资料」和「这条命令在哪版实际运行过」。

- 写作依据保留在 `omp/facts/` 文档切片与 `yuyu-book/sources-omp.json`；上游版本不自动更新。
- 本机输出与写作依据不一致时，现场操作按本机二进制处理；在 `omp/VERIFY.md` 登记差异与适用版本，再更新相关章和附录 E。
- 每次复验记录命令、退出码、时间与环境；使用 UTC 保存采集时间，同时注明 America/Adak 日期。
- 没有复验记录，不把旧版本结论改写成新版本事实。没有运行过的实验继续标「未验证」。
- 模型清单仅记录成功状态与输出形状；不保存私有网关名、模型配置、token 或账号信息。

## 最小复验

```powershell
omp --version
omp --help
omp models
```

在本机终端查看最后一条的结果，不将原始清单复制进仓库。联网模型实验单独执行并记录，
不把这三条只读命令的成功等同于模型请求成功。

标准矩阵见 `omp/VERIFY.md`；章末页边字段见 `omp/appendix-E.md`。
box 环境没有访问通道时保留历史记录，不能把 Windows 的复验日期写到 box 行。
