# Orca：并行 Agent 工作台

独立中文分册（非官方）。第一部包含前言与第 1 章，样章从「先确认跑的是哪个程序」进入：桌面包、命令行启动器、运行时三方对齐之后，再谈 worktree、编排与 bot。其余章节续写中。

源码固定为 `stablyai/orca` 的公开提交 `c354ab3`（MIT）。写作机器上安装了发布的 Orca 1.4.269，第 1 章的命令均在本机实测，输出原样引用；仓库 `package.json` 的 `version` 与发布 tag 不同步这一点，也在正文里写明出处。

## 构建

在仓库根目录运行 `python scripts/bookctl.py build --product orca --lang zh`。输出位于 `yuyu-book/dist/`，前缀为 `yuyu-orca-zh`。

本书为独立教程，与 StablyAI 无隶属关系。上游代码采用 MIT 许可，书籍内容采用系列许可；示例只用标准库与本机已安装的程序。
