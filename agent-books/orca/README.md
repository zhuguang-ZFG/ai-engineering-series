# Orca：并行 Agent 工作台

独立中文分册（非官方）。第一部已交前言与第 1–6 章：先确认跑的是哪个程序，再看一次开工作树的请求经过 git 与 Orca 两层登记落到哪里，把设置、规则与技能的落位认清楚，看并行的工作树之间什么隔离、什么共享，看多棵树怎样被编排成一支队伍，最后看远端的两条路——工作树出去还是运行时出去。其余章节续写中。

源码固定为 `stablyai/orca` 的公开提交 `c354ab3`（MIT）。写作机器上安装了发布的 Orca 1.4.269，第 1–6 章的命令均在本机实测，输出原样引用；仓库 `package.json` 的 `version` 与发布 tag 不同步这一点，也在正文里写明出处。

## 构建

在仓库根目录运行 `python scripts/bookctl.py build --product orca --lang zh`。输出位于 `yuyu-book/dist/`，前缀为 `yuyu-orca-zh`。

本书为独立教程，与 StablyAI 无隶属关系。上游代码采用 MIT 许可，书籍内容采用系列许可；示例只用标准库与本机已安装的程序。
