## 版本与来源

统一基线见 [sources.lock.json](../../agent-series/sources.lock.json)。标签必须解析到 commit，不能把 annotated tag 的对象 SHA 当成提交。DeepSeek Harness 固定完整提交，无 release tag 仍可复现；升级后另记差异。

事实分为钉版源码、文档陈述、处理器实验和完整宿主实跑。官网记录访问日期，不能凭新版文档证明旧版行为。回调单测不证明加载、权限或模型行为。

OpenCode v1.19.5 同时存在 V1/V2 入口，首个样例限定 V1。此前调研提到的 ctx.session.hook("context") 尚未核对到此基线，不写进 V1 教程。

Codex CLI 研究公开 Rust 实现、CLI/exec/app-server、配置、审批、沙箱、MCP、技能和恢复。桌面、云端及当前助手环境分别注明，不能借它们推断 CLI。

## 内容要求

各册包括上手、内部数据流、扩展、持久化、失败恢复和工程集成。插件专题覆盖发现、注册、调用时机、参数与返回值、状态归属、卸载、版本漂移和权限关系。

机制解释有源码落点；实验写输入、命令、可观察结果和失败路径。复杂调用链配图，选项用表比较。各章按内容组织，不机械重复固定句式。
