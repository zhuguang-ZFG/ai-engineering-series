## P6：比较入口与已修复的误报

新增 `bookctl video compare`，显式接收旧字幕、新流程的 transcript 和两份独立视频。
JSON 报告包含输入路径及 SHA-256、时间线、字幕逐条差异、视频时长与抽样帧结果。
只有证据齐全且全部匹配才返回 0；差异或缺证均返回 1。
报告路径不能覆盖任何输入证据。

```bash
python scripts/bookctl.py video compare --chapter ch01 --format long --legacy-captions /path/to/legacy.srt --current-captions video/.build/ch01/transcript-long.json --legacy-video /path/to/legacy.mp4 --current-video /path/to/current.mp4 --report .scratch/ch01-long-comparison.json
```

修复的判定问题：

- 字幕逐条比较文字；相同总文字无法掩盖词语落在错误时段。
- 帧在旧新版相同的绝对时刻抽取，保留 10%、50%、90% 三个采样点。
- 时长差超过 0.1 秒即为差异；相同帧无法掩盖延长的静止画面。
- 空采样、非法比例、非有限或非正时长、同一文件冒充两份视频均不能通过。
- 当前 transcript 必须属于所选章节和长短格式，具有有效的有序时码及非空文字。

6 项比较回归先在旧实现上失败，修复后通过；新增 CLI 测试也先复现入口缺失，
实现后通过。视频相关测试共 45 项。另以真实 FFmpeg 生成微型测试片段：
独立的两个 1 秒黑色视频判定 identical；1 秒和 2 秒片段即使三帧均相同，仍判定 different。
这些合成片段只验证检查器，不作为书籍视频的验收素材。
