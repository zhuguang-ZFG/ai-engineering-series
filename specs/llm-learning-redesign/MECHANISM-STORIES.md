# T16：让机制能一步步看清

状态：2026-11-07，0.14.0 本地技术完成。三套分镜、正文、书籍及以下检查已完成；发布与对应 CI 记录见 [PR #5](https://github.com/zhuguang-ZFG/vibe-coding-101-course/pull/5)。已发布基线为 T15 / 0.13.0，见 [PR #4](https://github.com/zhuguang-ZFG/vibe-coding-101-course/pull/4)。总计划和完成边界分别见 [PLAN.md](PLAN.md)、[ACCEPTANCE.md](ACCEPTANCE.md)。

## 1. 这次解决什么问题

已有实验能显示计算结果，但初读者仍要自己补上结果之间的过程：“概率出现”到“写出一个片段”之间发生了什么；注意力权重怎样变成一组新数；教师给出答案以后，学生参数究竟在哪一步改变。

本轮在 L02、L04 和 L05 的蒸馏段各增加一套手绘分镜。每套先用固定条件展开一次计算，再接原来的可调实验。相邻文字说明观看顺序、实际变化与原因，读者能停在任一步来回比较。动画只帮助辨认数据怎样流动，不用无限循环、打字效果或装饰性弹跳代替机制解释。

## 2. 三套分镜的数据边界

| 位置 / 图号 | 固定条件与来源 | 必须能看见的因果关系 | 必须保留的边界 |
| --- | --- | --- | --- |
| L02 / G49 / `generation` | `fixtures/generation.json`，温度 1、种子 42；调用 `core.cjs` 的既有概率和抽样计算 | 当前前文产生候选概率；选中一个片段后追加到前文；新前文产生下一轮候选 | 课程人工设定的有限状态教学模型；概率不等于杯中真实物品；抽样与重新计算是不同动作 |
| L04 / G50 / `attention` | `fixtures/attention.json`，第二个位置“把”，调用既有单头因果注意力计算 | 未来位置不能贡献内容；Q/K 比较得到可见分数，softmax 得到权重；各 V 按权重缩放后逐维相加 | Q/K/V 是课程人工矩阵；单头局部汇总不能当作模型完整思考；不混用深入段独立的 0.75/0.25 手算例 |
| L05 / G51 / `distillation` | `fixtures/distillation.json` 的默认教师、学生、T=2、α=0.7、学习率 0.4；调用 `distillation.cjs` 做一次更新 | 教师和学生在相同温度下比较分布；软硬目标共同给出梯度；学生分数更新后重新算概率，教师保持固定 | 只优化同一上下文的三个学生分数；教师概率不是事实证据；一步损失下降不等于掌握任务或已验证泛化 |

所有展示小数从上述计算生成，只在显示时四舍五入。构建会核对固定演示的候选顺序、矩阵和训练设置；这些条件发生变化时明确失败，要求一并复核图中算式与正文，避免旧标签配上新数据。网页逐步图、完整静态图和解释使用同一组计算结果；不能分别手抄一份概率。种子或任何固定条件改变时，图和文字应同时重建。

三张静态图登记在既有图册；每一套动态视图使用对应分步画面。图中用箭头、片段位置、条长、向量分量及教师/学生对照表达关系，不能只靠绿色或动画才能分清变化。实际显示尺寸下的数字和关键标签必须可读，长解释留给图旁文字。

## 3. 正文与静态阅读

正文保留既有标题、课号、公式、来源、旧图号及实验入口。新增位置采用 `<!-- mechanism: generation -->`、`<!-- mechanism: attention -->`、`<!-- mechanism: distillation -->`，由构建器插入对应分镜；不得把生成后的 HTML 当作另一份课文手工维护。

阅读顺序分别为：

1. L02 先预测哪个候选会被选中，看一次固定过程，再自己抽样、调温度和种子。
2. L04 先看“把”怎样汇总可见位置，再把未来 V 改大，用结果不变检验遮挡边界。
3. 蒸馏先区分“教师已给出信号”与“学生已更新”，再在实验里比较只改温度和真正更新一步。

页面默认提供完整静态图及顺序解释。JavaScript 未执行、初始化失败或被禁用时，这些内容仍能阅读；不能只留下播放按钮或一块空白。启用逐步视图后，读者仍可切回完整步骤。

PDF 与 EPUB 使用静态图和完整步骤文字，删除播放控件及重复的动态画面。原有公式、来源、自测、目录回链保留。三套机制都应能在书中独立读完，不能要求读者打开网页才能知道结果。代表页需实看图中文字、图注与解释的分页，不以成功生成文件代替阅读检查。

## 4. 播放与访问契约

| 行为 | 契约 |
| --- | --- |
| 初次打开 | 不自动播放；增强成功后停在第一步，当前步骤有文字说明 |
| 上一步 / 下一步 | 每次只切换一幅，边界不越界；手动操作停止正在进行的播放 |
| 播放 / 暂停 | 由读者启动，播放到本套结尾即停；暂停后不偷偷推进；重播从明确的起点开始，不无限循环 |
| 重置 | 回到确定的第一步，停止定时推进；同样条件重放得到相同数值和顺序 |
| 完整步骤 | 可查看完整静态图和说明，再返回逐步视图；切换时停止播放 |
| 减少动态效果 | 遵守 `prefers-reduced-motion`，关闭过渡和自动推进，仍能手动阅读全部步骤；运行中偏好改变应立即停下 |
| 离开阅读 | 页面进入后台时停止推进；若实现离开视口暂停，需实测不会因布局变化反复启动 |
| 键盘与焦点 | 所有操作使用原生按钮，焦点可见，操作后位置稳定；不自动抢焦点，不要求拖拽 |
| 读屏提示 | 手动变化用简短步骤状态提示；自动播放不持续刷屏，结束后给出一次清楚状态；图有可读替代说明 |
| 手机与放大 | 320、375、768、1440 CSS 像素及最大正文字号下无横向页面溢出，按钮至少 44 CSS 像素高，图和解释不互相遮挡 |
| 离线 | 本地文件打开即可使用，不需要账号、API 或远程资源 |
