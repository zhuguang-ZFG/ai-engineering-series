# 十二课图文阅读改版 · 0.11.0

日期：2026-11-07。任务：T13。状态：十二课主文、深入解释和蒸馏叙述已改写，G25–G48 直接穿插正文；网页、手机渲染、PDF/EPUB及本地完整检查已通过，发布与CI按PR #2最终提交追踪。本页记录设计与实际检查。证据统一进入 [ACCEPTANCE.md](ACCEPTANCE.md)、[IMPLEMENTATION.md](IMPLEMENTATION.md) 与 [REVIEW.md](../../design/system/REVIEW.md)。

用户指出“内容太枯燥、手绘太少”。此前概念和技术边界虽有覆盖，阅读仍常连续解释很久，部分图在课尾才出现。此次让图参与解释发生的过程：一个具体问题引出猜想，读者先观察或尝试，再用图看清变化及原因。保留原有二十四张图，新增二十四张，每课两张；四十八张是资产数量，不是“已经易懂”的证明。

## 阅读过程与保真要求

| 要求 | 如何检查 |
| --- | --- |
| 从读者能想象的问题开场 | 十二课开场能指出具体输入或工作情境，例如一句话、一份通知、一次乘法请求；不先堆定义和缩写 |
| 先猜，再有依据地核对 | 读者知道要看哪里、改哪个条件、比较哪两种结果；答案回到既有实验、原句或可复算数字，不能只靠作者宣布结论 |
| 图出现在需要解释的位置 | 每课一张靠近开场，另一张在相关正文、深入算例或蒸馏段；图片直接呈现，不能全部藏在末尾或折叠区 |
| 变化由构图说清 | 用切片、拼接、分岔、投影、遮挡、汇合、筛选、反馈或回执表示关系；图中文字标签简短，不能把长段文字搬进相同方框 |
| 图文交替继续推进问题 | 图前后有相关解释，图后说明刚才观察意味着什么；短课按语义位置安排，不为了凑间隔增加重复文字 |
| 简明但不删知识 | 保留原有公式、数值、代码、来源、否定、局限和独立信息；必要边界靠近例子，不能因减少免责声明而丢掉事实范围 |
| 不把模拟画成实测 | 人工概率、向量、通知、远端超时都注明性质；不填写 DeepSeek V4.1 Flash / Kimi K3 未采集的输出、内部参数或能力比较 |
| 静态读法同样完整 | 隐去图片仍有核心解释；网页无脚本、纸书和 EPUB 中能看见相同推演与答案，不留下只能点击才能理解的步骤 |

本轮采用 humanizer-zh 的事实保留和具体表达方法，以及 article-illustration-planner 的知识图解思路。通用规划中的相邻图至少间隔 400 字，不适用于用户这次要求更密集图解的短课：优先具体语义位置，图间保留必要解释，不为字数填充空话。这是对当前用户要求的落实，不是删减知识的理由。

## 视觉与构图约定

新图为 480×640 可编辑 SVG，沿用项目 FA-040 手绘线稿方向和 [tokens.css](../../design/system/tokens.css) 的纸色、墨线、绿色标记及少量橙色。正文使用清晰印刷字体；手绘感来自线条、局部标记与构图，不通过歪斜密集文字制造。

图型参考 IG-008 的流程与分路、IG-004 的对比、IG-002 的中心标注、IG-011 的变化对照；材料筛选另用 IG-013。编号用于记录构图意图，具体机制和图内事实优先。原始绘制代码为 [build-story-figures.mjs](../../scripts/llm/build-story-figures.mjs)，图的文件名、课号、目的、alt、来源和限制登记在 [figures.json](../../book/assets/handdraw/llm/figures.json)。

主要标签设计下限为 24px，按 327px 图宽缩放约为 16.4px；这只是设计值。验收仍要看真实字体渲染后有无裁切、碰撞、难辨连线和过密标签，并审看手机实际截图。颜色之外仍保留文字、线型和形状区分，不能仅凭红绿理解结果。
