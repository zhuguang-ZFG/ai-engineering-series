## 2. 任务依赖

```text
T00 基线整理 → T01 课程结构与构建约定 → T02 事实来源与纠错清单
                                             ↓
                       T03 L01/L02/L07 试点课文与数据
                                             ↓
                       T04 首批图解与实验 → T05 初学者试读
                                             ↓
                       T06 补全原理路线 → T07 补全应用路线
                                             ↓
                       T08 旧书互链与首页 → T10 核心课程验收
                                             ↓
                       T09 视频同步 → T10 视频补充验收
```

首批覆盖 L01、L02 和 L07，是为了验证“看懂机制→动手→用到任务”的教学方法，并不表示 O1–O5 已全部达成。

0.11.0 的 T13 接在已有 T12 内容基础上：逐课情境与阅读改写 → 新图与语义图位 → 网页构建/字形实看 → 同源 PDF/EPUB 重导出 → 本轮检查与发布。T05/T10 的真人验证继续独立等待，不因实施 T13 而关闭。

0.12.0 的 T14 接在已发布 T13 之后：修订具体阅读阻碍 → 导航与阅读控件 → 书籍目录与分节 → 实际浏览器与书页检查 → 本轮发布。编辑、网页与书籍按文件责任并行，生成成品统一集成；T05/T10 及独立阅读器、读屏实机条件继续保留。

0.13.0 的 T15 接在已发布 T14 之后：定位入口、回查与分页问题 → 并行完成根目录入口、手机导航和书籍连读 → 统一构建与正式导出 → 实际点击、键盘和书页核验 → 本轮发布。保留 T05/T10 和独立阅读器、读屏的外部验收条件，不把基线检查当作新版本结果。

0.14.0 的 T16 接在已发布 T15 之后：找出结果之间缺少的解释 → 并行完成计算分镜、播放器和正文 → 统一构建网页与静态书籍 → 检查数值、有限播放、减少动态效果、图文排版和既有阅读路径 → 提交发布并核对对应 main CI。三套各四步，先用固定条件看因果，再进入既有可调实验；不把技术检查当作真人学习效果。

## 4. 首次实施的具体切片

开始实施时按以下顺序做，不先铺满十二课：

1. 保存现有工作区状态清单，解决 T00 的两类基线问题。
2. 完成三节试点的课文骨架与源数据格式，先明确哪些是假设、哪些是真实计算。
3. 实现 X02 生成循环，用实际变化的分布驱动 G02；测试停止、重置与相同种子重放。
4. 实现 X01 的可复算分词示例和 X06 的通知核验练习。
5. 生成三个学习页面，接一个明确标注试读状态的入口；检查移动端，交给初学者试用。
6. 根据误解点修改课文和图，再扩展其他课程。

当前项目使用静态课程构建，不依赖文档站框架。`npm run build:llm` 生成网页与专题视频源码，`npm run export:books:llm` 导出书籍；`npm test` 检查数值、快照、构建一致性、书籍和媒体。浏览器交互、EPUB 重排及实机阅读分别保留证据，不能只运行 Markdown 检查就宣布课程可用。

## 7. 决策与风险

已采用的默认决策：继续以中文为主；沿用现有品牌与配色；先做静态及本地实验；保留编程实战；第一版不建立账号、学习排行榜或云端进度系统。

| 风险 | 处理 |
| --- | --- |
| 手绘看着亲切，机制仍抽象 | 先验证 G02 的“选中→追加→新分布”，用读者解释结果检查理解 |
| 简化造成新错误 | 每个实验写明模型范围和简化边界，技术核验先于口播和批量制图 |
| 书、页面、视频说法漂移 | 以课文事实和 sources 台账为准，衍生输出记录课号与版本 |
| 旧素材许可或来源丢失 | 保留既有署名与来源；新增来源台账；不把“公开可访问”写成“可任意再分发” |
| 全书太大导致范围失控 | 首批聚焦三课，其后只迁移与主线相关的章节；完整书继续可回查 |
| 缺少真实试读反馈 | 技术上通过不等于教学验收完成；交付时标明尚未验证的目标 |

用户已授权完成计划、生成本地书籍、提交、推送、合并并验证 CI；该授权继续有效。图形细节、文件命名和算法边界由以上约束决定，新增收费服务等超出已有任务范围的事项单独处理。
