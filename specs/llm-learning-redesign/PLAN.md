# 分阶段实施计划

状态：2026-11-07，当前版本 0.9.0。L01–L12、十七张手绘图、本地 PDF/EPUB 和六道陌生材料试读包已生成，九个目标旧章已修订，技术检查通过，待真实初学者试读。以下任务表保留完整范围；当前完成边界见末尾进度表与 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

优先级：先把一个学习单元做通，再扩展原理与应用路线，最后同步视频。预计工作量用于拆分批次，不能当作固定交期；试读排期、配音和渲染另计。

## 2. 任务依赖

```text
T00 基线整理 → T01 课程结构与构建约定 → T02 事实来源与纠错清单
                                             ↓
                       T03 L01/L02/L07 试点课文与数据
                                             ↓
                       T04 首批图解与实验 → T05 初学者试读
                                             ↓
                       T06 补全原理路线 → T07 补全应用路线
                                             ↓
                       T08 旧书互链与首页 → T10 核心课程验收
                                             ↓
                       T09 视频同步 → T10 视频补充验收
```

首批覆盖 L01、L02 和 L07，是为了验证“看懂机制→动手→用到任务”的教学方法，并不表示 O1–O5 已全部达成。

本计划不预设多 agent 并发改稿。对同一 `book.md` 的变更按章节顺序合入，每批核对锚点、来源和改动差异。

## 4. 首次实施的具体切片

开始实施时按以下顺序做，不先铺满十二课：

1. 保存现有工作区状态清单，解决 T00 的两类基线问题。
2. 完成三节试点的课文骨架与源数据格式，先明确哪些是假设、哪些是真实计算。
3. 实现 X02 生成循环，用实际变化的分布驱动 G02；测试停止、重置与相同种子重放。
4. 实现 X01 的可复算分词示例和 X06 的通知核验练习。
5. 生成三个学习页面，接一个明确标注试读状态的入口；检查移动端，交给初学者试用。
6. 根据误解点修改课文和图，再扩展其他课程。

## 7. 决策与风险

已采用的默认决策：继续以中文为主；沿用现有品牌与配色；先做静态及本地实验；保留编程实战；第一版不建立账号、学习排行榜或云端进度系统。

| 风险 | 处理 |
| --- | --- |
| 手绘看着亲切，机制仍抽象 | 先验证 G02 的“选中→追加→新分布”，用读者解释结果检查理解 |
| 简化造成新错误 | 每个实验写明模型范围和简化边界，技术核验先于口播和批量制图 |
| 书、页面、视频说法漂移 | 以课文事实和 sources 台账为准，衍生输出记录课号与版本 |
| 旧素材许可或来源丢失 | 保留既有署名与来源；新增来源台账；不把“公开可访问”写成“可任意再分发” |
| 全书太大导致范围失控 | 首批聚焦三课，其后只迁移与主线相关的章节；完整书继续可回查 |
| 缺少真实试读反馈 | 技术上通过不等于教学验收完成；交付时标明尚未验证的目标 |

当前无需额外确认即可继续完善本规格。实施阶段的图形细节、文件命名和算法边界由以上约束决定；只有新增收费服务、外部发布等超出任务范围的动作才另行处理授权。
