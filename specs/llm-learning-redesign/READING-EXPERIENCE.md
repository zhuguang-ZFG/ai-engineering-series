# 阅读体验改进 · T14

日期：2026-11-07。0.12.0 / T14 已完成正式导出和本地技术检查，已提交推送，发布状态见 [PR #3](https://github.com/zhuguang-ZFG/vibe-coding-101-course/pull/3)。用户要求继续优化阅读体验，本轮处理打开、连续阅读、查图、回查和重新接着读时的具体阻碍。现有四十八张图、公式与课程范围继续保留；新增阅读功能不代替真实读者验收，也不宣称体验已经达到“极致”。完整构建、书籍与发布结果由 [ACCEPTANCE.md](ACCEPTANCE.md) 和 [IMPLEMENTATION.md](IMPLEMENTATION.md) 记录。

## 阅读方向

- 产品：面向初学者的十二课大模型图解教材，网页能动手，PDF/EPUB能离线读。
- 使用情境：手机上读一小节，放大一张图，之后回到原位置；桌面上对照实验和推演。
- 表达：沿具体问题解释变化，数学符号第一次出现时能读懂它在做什么。
- 视觉：沿用纸色、墨线和绿色标记；导航与控件安静，手绘负责解释。
- 识别细节：课内目录连接相邻推演，放大手绘后能回到刚才的句子；本机位置记录只代表读到哪里。

本轮页面审查参考 unslop，Damir Sokolovsky，CC BY 4.0；[方法及归属](https://heydamir.design/unslop)。中文编辑继续按 humanizer-zh 保留事实、范围、数值、公式和确定程度。

## 编辑审查发现与修订

通读十二课主文、十二份深入解释和蒸馏长文后，按实际阻碍作局部修订，没有再次扩写全部课文。

| 位置 | 阅读阻碍 | 本轮处理 |
| --- | --- | --- |
| L02 生成公式 | exp 第一次出现时只有算法名，读者可能停在符号上 | 解释指数运算，并把归一化读成“算正数，再分份额”；原稳定 softmax 及温度边界保留 |
| L03 余弦公式 | 点积与向量长度同时写出，零基础需要回猜符号 | 补对应位置相乘再求和、两向量长度的读法；保留零向量未定义和事实置信度边界 |
| L04 注意力 | 实验已在上方，正文却说“下面直接给出小矩阵”；整式中的转置和维度缩放没有直读入口 | 修正指向，按转置/点积、缩放、遮挡、归一化、汇总的实际顺序解释，原公式与数值不变 |
| L05 基础训练 | 交叉熵中的 ln 未释义；基础梯度总结出现在长篇蒸馏结束之后 | 补自然对数和罚分方向，将既有基础梯度段移至蒸馏占位之前；按基础更新、深入算例、蒸馏连续阅读 |
| L05 蒸馏 | i/j、Σ、ln、学生分数与偏导连续出现，读者易混淆“候选单项”和“完整损失” | 给每条长公式补短读法；说明单项可负而 KL 总和非负，梯度描述分数变化对损失的局部影响；保留原公式、配方条件和错误教师实验 |
| L07 开场 | “手里只有这一句通知：”后先出现整张图，通知原句被隔开 | 将通知原文和地点问题连着呈现，再接工作台图；图号和材料不变 |
| L10 深入段 | 构建把深入解释插在“再深一层”前，后者却说“接下来的超时图” | 改为回看上方超时图，保留有限状态、预算和授权说明 |

这些是编辑和结构检查的结果，不是真实初学者的卡点统计。其余课文已具备具体情境和操作路径，本轮保留，不为扩大改动量而换同义词。

## 网页阅读契约

| 要解决的事 | 实现约束 | 验收证据 |
| --- | --- | --- |
| 打开手机课文能立即开始 | 十二课总目录默认收起，仍可用原生展开控件访问；课名和开场不被长导航推到屏幕之外 | 375px与窄屏实际首屏截图；无脚本时目录仍可展开 |
| 长章节能回查 | 课内目录由实际正文标题生成；唯一稳定锚点，链接到存在的小节；跳转后焦点进入目标 | 链接与ID检查；键盘激活、回退和深链接实际操作 |
| 字号适合自己的眼睛 | 标准/较大/最大正文级别；控制文字清楚，本机记住设置；存储不可用也能读 | 三档字号、刷新及跨页保留；最大字号无正文横向溢出 |
| 看清图内过程 | 有明确“看大图”入口；放大层可键盘操作、Escape关闭、焦点回到入口；无脚本可直接看原图 | 手机放大实际截图；对话框焦点与关闭测试；原图链接可用 |
| 中断后能接着读 | 提供可选的继续位置，保留课号和小节；初次打开不强制跳动；只接受课程内有效记录 | 保存/恢复、无效或旧记录、存储拒绝测试；不把位置记录称作学习完成 |
| 连续阅读不被功能打断 | 控件不遮挡正文、公式或操作按钮；减少动态效果偏好有效 | 375/768/1440布局、200%缩放、离线与键盘检查 |
| 停用脚本也完整 | 正文、图、公式、静态实验与答案继续可读，目录和原图链接可用 | 禁脚本逐课检查；不留下只能操作但没有说明的空区域 |

字号、位置保存和图放大属于阅读帮助，不新增账号、在线追踪、学习成绩或真实读者数据。来自本机存储的值也须校验，不能变成任意外部跳转或可执行内容。

## PDF 与 EPUB 阅读契约

| 要解决的事 | 实现约束 | 验收证据 |
| --- | --- | --- |
| PDF 能按目录翻到章节 | 目录页码来自本轮实际排版结果；重排后重新计算，不能手填或沿用旧页数 | 目录页码与实际章节起始页逐项比对 |
| EPUB 能直接进入小节 | 章节下提供实际小节导航，目标存在、顺序一致；有效跨课链接保留 | 官方EPUBCheck、本地链接/锚点检查及字号重排 |
| 图文连读 | 图与说明相邻，标题不孤立；公式、短表和图注不被裁切或拆坏；不靠缩小正文掩盖空白 | 实际抽看开场、长公式、蒸馏表、应用页和稀疏页 |
| 阅读器控件不进入纸书 | 字号选择、继续位置、图放大按钮与运行时弹层从书籍移除；原课文和四十八图保留 | PDF文本、EPUB结构及每图一次检查 |
| 成品与源码一致 | 新版网页、PDF、EPUB按同一课文生成，清单与官方校验绑定本轮成品 | 源指纹、文件SHA、完整书籍检查和代表页实看 |

技术检查通过后，还需按 T05/T10 取得真实初学者记录，观察是否容易定位、恢复和理解。独立阅读器与真实屏幕阅读器的实机证据继续单列，浏览器重排和可访问性树不能替代。
