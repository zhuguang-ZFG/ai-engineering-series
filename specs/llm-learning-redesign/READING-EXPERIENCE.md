## 阅读方向

- 产品：面向初学者的十二课大模型图解教材，网页能动手，PDF/EPUB能离线读。
- 使用情境：手机上读一小节，放大一张图，之后回到原位置；桌面上对照实验和推演。
- 表达：沿具体问题解释变化，数学符号第一次出现时能读懂它在做什么。
- 视觉：沿用纸色、墨线和绿色标记；导航与控件安静，手绘负责解释。
- 识别细节：课内目录连接相邻推演，放大手绘后能回到刚才的句子；本机位置记录只代表读到哪里。

阅读改进参考 unslop，Damir Sokolovsky，CC BY 4.0；[方法及归属](https://heydamir.design/unslop)。中文编辑继续按 humanizer-zh 保留事实、范围、数值、公式和确定程度。

## T15 问题与契约 · 0.13.0

用户询问本地 PDF 和 EPUB 在哪里，需要从项目根目录就能打开成品。长课读到中途时，手机上的课内目录也需要随时可达。成品审查已定位两处书籍问题：0.12.0 PDF 的 KL 公式在第 57 页末、解释在第 58 页；EPUB L05 的返回目录入口只有章末一处。以上是用户反馈与成品检查，不是真实初学者试读统计。

| 阻碍 | 本轮实现契约 | 验收方式 |
| --- | --- | --- |
| 不容易找到本地书籍 | 根目录 `开始阅读.html` 直接链接 PDF、EPUB 和网页；课程页脚提供书籍入口，说明格式与用途 | 实际从本地文件打开并逐个点击；相对路径有效，离线与无脚本可用，无需开发服务 |
| 手机读到中途不便查目录 | 提供“本课目录”对话框，沿用正文实际小节与稳定锚点 | 在长课中途打开、键盘选择与关闭；Escape 和关闭按钮返回入口焦点，选择小节后焦点进入正文目标 |
| 不清楚目录中正在读哪一节 | 当前小节随阅读位置静默标记，保留可辨识的文字或语义状态 | 滚动和直接跳转后指向正确小节；不使用持续播报，不把浏览位置等同完成状态 |
| 放大后看不到图注 | 大图呈现原图注与读图上下文，使用同一来源，不维护另一个事实稿 | 逐图核对图与图注对应；长图注、最大字号及窄屏可读，关闭后返回原入口 |
| 公式与解释跨页割裂 | 独立公式与紧随解释在页内可容纳时保持相邻；长内容允许合理拆分，不删公式、不缩字 | 重导出后实看 KL 已知问题与其他受影响公式，核对公式、解释、中文与边界，记录实际页数变化 |
| EPUB 需读到章末才能回目录 | 章首及课内小节提供回到目录中本课位置的入口，目录能再进入具体小节 | 检查每个回链目标与往返；字号重排、实际点击和 EPUBCheck 通过后记录新成品哈希 |

本轮沿用四十八图与全部课程内容，网页新增控件不进入 PDF/EPUB。所有新增入口、导航、图注和分页改动须重新检查；0.12.0 的测试、页数与绿色 CI 不能作为本轮结果。

## T14 编辑审查发现与修订 · 0.12.0

通读十二课主文、十二份深入解释和蒸馏长文后，按实际阻碍作局部修订，没有再次扩写全部课文。

| 位置 | 阅读阻碍 | 本轮处理 |
| --- | --- | --- |
| L02 生成公式 | exp 第一次出现时只有算法名，读者可能停在符号上 | 解释指数运算，并把归一化读成“算正数，再分份额”；原稳定 softmax 及温度边界保留 |
| L03 余弦公式 | 点积与向量长度同时写出，零基础需要回猜符号 | 补对应位置相乘再求和、两向量长度的读法；保留零向量未定义和事实置信度边界 |
| L04 注意力 | 实验已在上方，正文却说“下面直接给出小矩阵”；整式中的转置和维度缩放没有直读入口 | 修正指向，按转置/点积、缩放、遮挡、归一化、汇总的实际顺序解释，原公式与数值不变 |
| L05 基础训练 | 交叉熵中的 ln 未释义；基础梯度总结出现在长篇蒸馏结束之后 | 补自然对数和罚分方向，将既有基础梯度段移至蒸馏占位之前；按基础更新、深入算例、蒸馏连续阅读 |
| L05 蒸馏 | i/j、Σ、ln、学生分数与偏导连续出现，读者易混淆“候选单项”和“完整损失” | 给每条长公式补短读法；说明单项可负而 KL 总和非负，梯度描述分数变化对损失的局部影响；保留原公式、配方条件和错误教师实验 |
| L07 开场 | “手里只有这一句通知：”后先出现整张图，通知原句被隔开 | 将通知原文和地点问题连着呈现，再接工作台图；图号和材料不变 |
| L10 深入段 | 构建把深入解释插在“再深一层”前，后者却说“接下来的超时图” | 改为回看上方超时图，保留有限状态、预算和授权说明 |

这些是编辑和结构检查的结果，不是真实初学者的卡点统计。其余课文已具备具体情境和操作路径，本轮保留，不为扩大改动量而换同义词。
