## 设计与内容

二十四张 SVG 采用已有纸色、墨线与绿色标记。G01–G17 连接原理与应用，G18–G24 增加蒸馏、语境表示、梯度、训练信号、检索失败、超时和独立评测。新增图最小标签 24px，在 327px 显示宽度下约 16.35px；实际字形边界另行检查。图放在相关问题与计算附近，来源、目的、简化边界、替代文本与移动策略登记在 `book/assets/handdraw/llm/figures.json`。

正文维护在 `book/llm/lessons/`，课程与自测维护在 `course.json`，来源与技术纠错状态维护在 `sources.json`。`marked@18.1.3` 负责 Markdown 解析；页面、样式和脚本由 `npm run build:llm` 生成，`--check` 比较生成内容，防止只手改输出。

分词使用 `js-tiktoken@1.0.21` 的 `cl100k_base`、`o200k_base` 本地导出结果。原始字节从公开 rank 数据解出，保留哈希；没有把单个 token 错解为完整 UTF-8 字符。生成实验是人工有限状态模型，概率当场计算。通知核验是基于人工事实标注的预置练习，所有页面都明确区分数据类型。

X03 的数字是人工示意；X04 执行单头因果注意力但 Q/K/V 人工给定；X05 真正更新 bigram 参数并计算交叉熵，不是 Transformer；D06 回答为教学编写，未运行三个训练检查点。主线与深入解释分层，自测答案也用于静态阅读。

实际模型案例按需求采用 DeepSeek V4.1 Flash 与 Kimi K3。`models.json` 保存官方链接、核验日期、版本说明、同题任务和复做记录字段；未采集模型输出或性能跑分。DeepSeek 官方首页在核验时将 `deepseek-flash` 指向 `DeepSeek-V4.1-Flash-1017`；K3 与当前平台另列的 K3.1 Pro 分开，不把后续版本规格写给 K3，也没有猜测未核验的 K3 API ID。

L08 的引用存在与事实支持分别检查；X07 是共享字符二元组检索，只有正分命中片段进入输入，整理只使用片段中的事实标注；X08 是白名单四则运算状态机，一轮最多执行一次，失败/取消不显示成功。D11 使用有条件的方案练习，D12 保留缺失、冲突、无关或范围外状态；勾选只是人工自查声明，不充当质量证明。

首页、README 与书首同步十二课与电子书入口。学习页目录、附图尺寸、开放数量由元数据生成；主首页的课数与 X 系列实验数量由构建更新并在 `--check` 中核对，避免手写数量漂移。原有书籍锚点保留。

## PDF 与 EPUB

`npm run export:books:llm` 从相同网页的静态实验与课文生成本地成品。PDF 为 A5，包含可选择中文、内嵌字体、页码、书签与矢量手绘图。EPUB 为流式 XHTML，目录覆盖十二课及实际模型练习，使用同图 PNG 和阅读器字体；正文可调字号。交互按钮改为纸上步骤与结果，答案保留，不模拟离线运行网页实验。PDF 把主图和章题排在一起，避免高图在后续分页时留下大片空白；清除纸面无法访问的维护台账入口，避免孤立一行单占一页。最终页数见交付 JSON 清单。

成品、字节数、SHA-256 与源文件指纹记录在 `deliverables/llm-explained-handdraw.json`。源文件改变后，`check:books:llm` 会失败并要求重建；PDF 不承诺含时间元数据的二进制逐字节相同。Python 依赖记录在 `scripts/llm/requirements-books.txt`，无远程字体或模型 API 依赖。

正文去掉宣传式铺垫，以具体错误、材料、动作与后果解释概念。保留公式、版本、人工示意范围与未完成状态；未制造教师经历、用户人数、模型输出或学习提升比例。样例：“很有信心的回答”落到“地点能否在原文找到”，“资料已接入”落到“本次真正取回了哪些片段”。
