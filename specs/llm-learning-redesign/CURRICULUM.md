# 课程、手绘与实验设计

本文保留课程设计与实验契约，配合 [SPEC.md](SPEC.md) 与 [PLAN.md](PLAN.md) 使用。当前 0.10.0 的逐课知识点与复做入口见 [KNOWLEDGE-MAP.md](KNOWLEDGE-MAP.md)。表中的课时为初始预算；新增深入段可分次阅读，实际用时须经试读校准。

## 1. 三种读法

| 入口 | 建议顺序 | 完成后应留下什么 |
| --- | --- | --- |
| 先看明白，约 30–45 分钟 | L02 体验 → L01 → L05 概览 → L07 → L08 | 一张自己画的生成流程、一份带证据的待办表 |
| 认真理解，每课 15–25 分钟 | L01–L11；需要时展开公式层 | 能解释、能复算的小实验记录与错误排查方法 |
| 做成作品，另计项目时间 | L12 → 现有“接入真实 AI 能力”“打磨并交付” | 可演示作品、测试材料、使用边界与验收记录 |

不在入口一次列出所有缩写；卡片标题用问题，术语在进入该课后解释。每课保留“先看懂 / 动手试 / 再深一层”，层次递进且可以返回。

| L06 会续写为什么还需要学会听指令？ | 预训练、SFT、偏好优化、聊天角色格式；评价不等于真理 | G07；记录示例对照，显式标来源 | 不把礼貌、流畅、自信当作事实依据 | 解释模板、训练与推理的不同作用；知道对齐不保证正确 |
| L07 怎样把一件事交代清楚？ | 目标、材料、约束、输出形式与检查；上下文预算 | G08；X06 通知材料→待办表 | 整理会议、阅读通知、提炼行动项 | 对“地点”缺失的材料输出“材料未提供”，不凭空补齐 |
| L08 怎样发现一个看似合理的错误？ | 幻觉、缺证据、冲突资料、外部核验；可靠性与生成概率不同 | G09；X06 注入错误日期和虚假引用 | 核对摘要、数字、出处与代码结果 | 找到错误所在和对应材料；不能只让模型“再认真检查一次” |
| L09 怎样让它用上自己的资料？ | 切块、检索、取回、构造上下文、带证据回答 | G10；X07 从小资料集找答案 | 产品手册、课程笔记、内部制度问答 | 区分没检索到与模型没用好；说明 RAG 没改模型参数 |
| L10 怎样让模型调用计算器或其他工具？ | 结构化请求、外部执行、返回结果、停止与权限 | G11；X08 沙盒计算器与失败分支 | 精确计算、查数据、受控工作流 | 区分计划与执行；工具出错时不能显示“已完成” |
| L11 什么时候直接提问，什么时候要搭系统？ | 提示词、RAG、工具、微调的适配条件；成本、延迟、质量与评测 | G12；五个场景做选择并解释 | 为具体任务选择方案，避免一开始就搭复杂 Agent | 新资料检索、统一输出习惯、精确运算各选对能力并给理由 |
| L12 做一个能交付的资料助手 | 把前面的方法串成受控任务，测试陌生输入与失败情况 | G13；综合材料包与验收表 | “活动通知→待办表→冲突/缺失报告→导出” | 结果可追溯；资料不足会停；能向别人说明边界 |

L12 提供两个难度：不用代码的材料核验工作流，以及沿用现有课程方法做成网页。两者使用相同资料、输出标准与测试集，不能以有没有写代码来判断是否学会原理。

## 4. 实验共用契约

每个实验必须写出输入、用户操作、状态变化、观察结果、错误状态、重置规则和测试断言。禁用纯播放动画冒充可操作实验。

数据最小字段：`id`、`kind`（toy / illustrative / recorded）、`source`、`version`、`limitations`、`expectedObservations`。仅 recorded 类型需要真实模型或 tokenizer 版本、采集日期和运行参数；未采集时不得编造这些字段。

### X01 分词观察

- 输入：首批四组锁定示例，包括中英文、空格标点、罕见字符及 emoji。自由输入为后续增强，不在未接入真实 tokenizer 时伪装支持。
- 数据：使用明确 tokenizer 版本导出的 token ID 与原始字节片段。导出脚本与依赖版本进入仓库；第三方词表遵守其许可。
- 交互：选择输入、切换两种已验证编码、定位某个片段、还原原文。
- 显示：字符数与 token 数分开；emoji 字素、Unicode 码点和字节也不得混称“字符”。展示字节片段时允许单个 token 不构成完整 Unicode 字符。
- 验收：按字节拼回原文无损；前导空格、换行与标点不丢；不能用逐字拆分冒充 tokenizer。

### X02 候选与采样

- 输入：一个明确标为“教学模型”的小型上下文状态表，每个状态有固定词表 logits；支持句子生成到终止符或长度上限。
- 交互：温度 0–2、单步生成、重复 100 次抽样、重置种子；同一上下文下先比较分布，再观察选择。
- 计算：`T > 0` 用稳定 softmax；`T = 0` 取 argmax，平局按固定 token ID 顺序处理。已选 token 追加后重新查当前状态，不能永远展示一张不变概率表。
- 边界：对未知状态明确显示“教学模型未覆盖”，不偷偷改成随机回答；停止符不作为正文显示。
- 验收：概率和在容差 `1e-10` 内为 1；不产生 NaN；相同输入、配置与种子重放一致；长度限制生效。此复现保证仅指本地教学程序。

### X03 向量与投影

- 输入：两组使用同一词但语境不同的例句；采用明确标为“示意”的小向量表。
- 交互：比较 ID、初始查表向量和经过上下文处理的示意表示；展开原始数字，查看余弦相似度。
- 边界：投影位置由固定输入生成，不能随页面刷新随机变化；示意图不声称给出了真实词义坐标。
- 验收：相似度由显示的数字算出；零向量有明示处理；用户能指出“同一 token ID 的初始向量”与“不同上下文后的表示”的区别。

### X04 因果注意力

- 输入：一条短句的人工小矩阵 Q、K、V；页面持续标注“教学矩阵”。
- 交互：选择当前位置、查看可见前缀、查看掩码和归一化权重；只修改未来 token，观察较早位置结果。
- 计算：按公式执行掩码、softmax 与 V 的加权汇总；同时说明多头和其他网络层未在此小实验全部展开。
- 验收：未来权重为零；可见权重和为 1；修改未来值不影响较早位置输出；边界位置也没有 NaN。换整句的预设时同时更新矩阵来源说明。

### X05 训练小模型

- 模型：本地 bigram softmax，参数为“前一个 token→下一个 token”的 logits 表；明确不是 Transformer。
- 语料：少量人工教学句子，训练集与未见组合分开。学习率和步数固定上限，提供单步更新、连续运行、暂停、重置。
- 显示：同一目标的更新前概率、损失、梯度方向和更新后概率；让读者看到具体哪个参数改变。
- 说明：有限语料可能过拟合；无法因 toy 模型效果推断大模型规模规律。训练曲线实算，不能预画一条下降线。
- 验收：固定语料、种子和温和学习率的基线在指定步数后训练损失降低；无需保证每一步或任何参数都降低；推理步骤不改参数；中止后状态停止变化。

### X06 材料与结果核验

- 练习材料：`通知A：读书会周六14:00开始，参与者需提前报名。` 另附两个版本：一个遗漏地点，一个写明已改到周日。
- 输出字段：活动、时间、地点、报名要求、证据片段、缺失/冲突说明。
- 交互：用户选择相关材料，比较两份标为“预置练习回答”的结果，标记无证据结论，再展示反馈。离线版不假装生成了新自然语言回答。
- 验收：遗漏地点必须标出；冲突必须显示来源与版本；“周六”没有日历基准时不能擅自换成具体日期；引用必须与对应材料匹配。

### X07 检索与生成的分工

- 输入：带稳定文档 ID 的小资料集，包含近似主题、无关片段、旧版和新版规定。
- 计算：第一版用可解释的词项检索展示流程，明确说明它是教学检索器；嵌入检索为后续可选对照。
- 交互：改查询词、片段大小和取回数量，展示实际命中片段与加入上下文的内容；回答使用标注来源的练习样例。
- 边界：查询无匹配时返回“未找到”，不强行把得分最低的文档称为证据；过期资料不因相似度高就变成现行规则。
- 验收：点击引用能定位文档与片段；空查询、无结果和冲突均有路径；参数没有被检索操作修改。

### X08 工具调用

- 输入：结构化的四则运算请求，只接受白名单运算符与有限数值；不执行任意代码或 `eval`。
- 状态：待调用→参数校验→执行→结果返回→结束；另有无效输入、除零、模拟超时和取消分支。
- 交互：单步展示模型建议、外部程序动作与返回值，点击失败场景查看停止原因。
- 边界：所有动作在本地沙盒中；发送消息等外部动作只用模拟示例。可选多步演示限制最多三次工具调用。
- 验收：错误不显示成功结果；调用次数到上限会停止；没有真实网络副作用；计划文字与执行回执分开。

### X09 三候选蒸馏

- 输入：已核实硬目标“水”，教师 logits `[3,2,0]`，错误教师 `[0,3,2]`，学生从零分开始。候选为水/茶/咖啡，全部标为人工教学数据。
- 计算：`αT²KL(p(T)‖q(T))+(1−α)CE(y,q(1))`；显示两项损失、梯度及真实更新。教师固定，学生分数是本实验参数。
- 操作：温度与软目标权重、教师切换、一步/25 步、重置；100 步上限。条件改变后重置学生并说明。
- 观察：默认 T=2、α=.7、学习率 .4；错误教师让第一步水的推理概率从 33.33% 降至约 32.03%。α=0 时只学硬标签，不能据此推成所有任务的最优配方。
- 验收：混合梯度与独立有限差分一致；教师不变、学生随操作更新；边界输入拒绝；无脚本/电子书表来自同一计算。说明词表对齐和文本蒸馏的区别，不声称复制隐藏思维。

## 5. 第一课体验样稿：一句话是怎样接出来的

以下是 L02 的教学新稿示例，用于定调和首批制作，不是对旧文的逐句润色。

> 在输入框里选“他端起杯子，喝了一口”。先猜一下，后面可能接什么。
>
> 这页准备了一个很小的教学模型。它会给“水”“茶”“咖啡”等候选片段打分，再把分数转换成概率。屏幕上的数值是为了演示而设定的，不是从某个聊天软件里读出来的。
>
> 点一次“生成一步”。被选中的片段会接到句子后面，新的句子又成为下一步的输入。重复这个过程，就能生成更长的回答。真实模型使用自己的分词器和学到的参数，候选规模也大得多。
>
> 把温度调高，再试几次。你会看到候选之间的概率差距变小，原本不常出现的片段更有机会被选中。调低温度，选择通常更集中。
>
> 这还不能告诉你杯子里究竟装了什么。模型对某个片段给出较高概率，只表示它在当前条件下更可能接出来。如果原材料没有说明杯子里是什么，可靠的整理结果应把这件事留作未知。

画面顺序：原句纸条→候选条形分布→抽中片段→追加→下一轮。解释公式时再展开 logits，不在首屏同时展示所有术语。

自测：

1. “茶”的概率最高，就能确定杯子里是茶吗？不能；这是续写分布，不是对现实事实的核验。
2. 为什么生成一个片段后要更新输入？后续候选依赖包含这个新片段的上下文。
3. 温度调低能补上材料中没写的地点吗？不能；需要取得材料或明确标记未知。

应用迁移：让模型从活动通知提取地点。材料没有地点时，检查它是否留空并说明缺失，而不是根据常见场所补一个看似合理的答案。

## 7. L12 交付与迁移验收

最低交付物：一份输入材料、任务约定、结果表、逐条证据、错误记录和使用说明。网页版本再增加可运行页面与操作演示。

固定测试集覆盖：材料完整、地点缺失、两版日期冲突、无关材料、资料中的恶意指令、工具除零、检索无结果以及超出范围的问题。处理资料中的“忽略规则”等文本时，将其作为待处理内容，不执行它。

随后换一份课程未演示过的材料，让读者独立完成同类任务。不能只检查是否照抄了提示词，需检查他能否解释“为什么要给这些材料、哪里需要核验、失败时停在哪里”。
