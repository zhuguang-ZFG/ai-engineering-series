## 核验和保护

- 原章之外的前缀和后缀在修订前后逐字散列相同；检查 36 个标题及顺序保持一致。没有全书机械替换。
- `npm run build:llm` 组装同源稿并生成分词表；`--check` 检查旧章、旧图入口与输出页一致。继续保持原书行尾格式。
- 分词先独立复算两种编码；编号不按单字独立解码，不把部分 UTF-8 字节变成替代字符。完整 MIT 许可保留。
- 阅读页新增链接经本地文件检查；PDF/EPUB 用实际成品检查目录、可提取中文、页边界、引用和源文件指纹。
- 原始资料、修订前章稿与核验快照保存在被忽略的 `tmp/llm-correction-sources/`，用于本地复核；正式来源、方法、适用范围与日期维护在 `book/llm/sources.json`。
