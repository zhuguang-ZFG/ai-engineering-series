## 插图与阅读

六张原书插图在原路径重绘：学习路线、排错、部署、索引、架构、Git。继续使用纸色、墨线与浅绿的视觉体系；正文标注至少 26 SVG 像素，480 像素画幅在 320 像素手机文本栏中约为 15.6 像素。已查看实际渲染，检查文字边界、箭头走向和图文一致性。注意力、残差、多头、训练四张机制图也已放回原章对应解释附近。

原稿按 Markdown 语法解析，保留所有原有三级章节，不把围栏内的示例标题误算为章节。生成页面提供章内目录、上下章链接和完整目录；宽表与代码在自身区域滚动，正文重排。构建时逐项检查书内锚点和文件引用，`npm run check:book` 防止正文改了而阅读页未更新。

浏览器实测：198 个页面（196 个原书页面及两个入口），每页检查 320px/18px、375px/24px、768px/18px 三种窗口与字号，共 594 组；4,992 处本地链接及资源引用可达，图片正常加载，无页面水平溢出。还实测了主入口、原书目录到排错章节的跳转和键盘跳到正文。测试使用离线 Chrome；并非外部网页可用性或所有独立电子书阅读器的测试。

## 验收口径与复核
