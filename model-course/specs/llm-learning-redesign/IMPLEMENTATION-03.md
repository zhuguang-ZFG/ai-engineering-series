# 教材迭代 03：精确引用位置与完整模式对照

日期：2026-11-08 至 2026-11-09。范围为抽取契约的精确文档位置、模式适用边界及原冻结八题的 0.5B 独立对照；课程为 1.1.1 技术试读版。原计划的 1.5B 新版本复测因资源压力未完成，保留为待复测。课程主线和 K1–K5 判据不变。

## 本批实现

- fixed/extract 的引用新增 `quote_start/quote_end`，标记 `config.claim_contract=source-extract/2`。保留原 chunk 的 start/end 和模型给出的 quote，默认 copy/agent 与旧报告结构兼容。
- 匹配只折叠空白，程序保留从匹配字符到文档字符的位置映射；坐标基于去 UTF-8 BOM、统一换行为 LF 后的 Unicode 码点，采用半开区间。同一 chunk 中的重复引文取第一次匹配，哈希仍绑定文件原始字节。
- `agent + extract` 在读取资料、检索及调用模型之前返回 invalid-request，配置错误不会被零命中或缺文件状态遮盖。
- JSON 和 Markdown 都给出精确位置；C13/C15/C17、C13 分离答案和助手 README 同步说明坐标、回查、重复匹配及兼容条件。修正 README 中 copy 必须等于整段 quote 的错误说法，以及不符合实际摘录合同的报告示例。
- C13 的 inspect read 原命令漏了必填 --doc，实际退出 2；补上 --doc station-log 后退出 0，并按实际 doc/text 字段修正说明。
- 扩展核对发现 C17 的同类遗漏：补上 --doc equipment-guide，并把“列出可见文档”改为读取单份指定材料。C11–C30 中 36 条助手命令通过参数解析检查；这只是语法/必填参数检查，不冒充真实模型、服务或全章实跑。
- C14 原练习把未固定哈希的课程清单交给要求 sha256 的程序，还使用不存在的 sample_docs 路径。现增加独立副本与一次性固定摘要步骤，统一清单目录路径基准，区分维护者盘点与读者权限，修正撤回文档的方法。正文程序直接抽取执行，正常五项及七种失败/重复准备情形均核对。
- C16 补上工具请求必需的 action=tool；按实际 CLI 修正未知工具的退出码/阶段，正文与分离答案一致。计算示例实际得到 42，未知模型请求在执行前拒绝，未知 CLI 工具在参数解析时退出 2。
- 新增 14 项标准库测试，覆盖空白/Unicode、文件解码与哈希、重复/重叠片段、无效引文、伪造字段、冲突/不足、默认兼容、提前拒绝和 Markdown 回显。测试文档是合成材料，不是模型质量结果。

## 验收边界

精确位置只能帮助回查，不能判断引用的适用性、遗漏条件或冲突。完整八题中 agent/extract 仍按原期望回答/工具回执评分，不删题，也不把不支持改成成功；同时单列七题 fixed 子集，解释两种口径的差别。模型失败、独立复做和真人教学验收继续分别记录。
