# 书籍工艺与深读改版 · 05

日期：2026-11-10。触发：用户指出“书籍还不够漂亮优美，内容也不够有深度，插画也不漂亮”。本批把这三个问题分开处理：书先成为一本真正的书，图先成为一套图，正文再补一层能被复算和检验的深度；不以增加装饰或空泛议论代替。

这是本批的设计与内容 spec，也是验收口径。历史成品和旧批证据保持原样，不拿旧页码、旧哈希或上一批 CI 代表本版。

## 2. 版式系统

纸张 A5（148 × 210 mm），正文 10.5 pt，行高 1.78，页边距 15–19 mm。正文用 Noto Serif SC / 宋体，标题、图注、目录和页眉用 Noto Sans SC / 黑体，形成“正文静、标题立”的层级，而不是全页一个字号。

| 页 | 设计 | 目的 |
| --- | --- | --- |
| 封面 | 暖纸底、细双框、衬线书名、五块等轴薄板叠成阶梯，其中一块抽出 | 一眼看出“五阶段”和“拆开看”，不靠截图或机器人 |
| 书名页 | 大留白、短副题、一条松绿短规线 | 从封面进入正文的呼吸页 |
| 读法页 | 一条线五种读法、图号说明、纸书/电子书边界 | 让读者知道这本书怎么用，而不是直接掉进第一章 |
| 目录 | 阶段行 + 章行，点线引导，右对齐实际页码；两页排完 | 目录是书的地图，不是网页链接的打印版 |
| 阶段页 | 第一页整版阶段插画，第二页阶段号、论点、导言、章节清单 | 给五个阶段各自一个“门口”，也让长书有节奏 |
| 章首页 | 松绿章号、阶段/能力门、23 pt 章题、章摘要、1.5 pt 横线 | 每章重新开始；摘要先告诉读者这一章解决什么 |
| 正文 | 首行不缩进、段距 0.72 em、两端对齐、三线表、图注左对齐、图号在句首 | 中文长文的稳定阅读节奏 |
| 页眉页脚 | 书名 / 五阶段三十章；页码居中；封面、书名页、阶段插画页不显示 | 翻页时知道自己在哪，展示页保持干净 |

章首页的编号使用 `C01` 而不是“第一章”，与课程网站、答案文件和阶段页保持同一套编号；页眉只放书名与全书结构，不冒充章节名。

## 3. 内容加深

### 3.1 章摘要

30 章各加一条 30–50 字的摘要，放在章首页。摘要不复述标题，而是说清“这一章把什么变成什么”。例如 C01：“把一条通知变成一份每格都能回到原句的资料报告，并学会保留‘未知’和‘冲突’。”摘要是给翻书的人用的，不替代正文。

### 3.2 阶段导言

每阶段两段、约 250 字，说明这一阶段练什么、哪里容易误判、和下一阶段怎么接。导言不重复章节标题，也不写“本章非常重要”一类空话；它给出阶段内的共同动作，例如 S3 的“让失败留下回执”、S4 的“先有尺子，再谈变好”。

### 3.3 深读文章

书末新增《深读：五个不能再简化的问题》，五篇分别对应五个阶段：

| 篇 | 问题 | 可复算/可检验的内容 |
| --- | --- | --- |
| S1 | 一条结论要经过几次交接，才仍然可信 | 主张—证据位置—支持关系—状态四元组；五种状态；重复字符串、版本过期、范围与否定丢失；“陌生人两分钟规则” |
| S2 | 一次注意力到底做了多少乘法 | 点积方差与 `√d_k` 缩放；`d_k=64` 时分数差 8、比值约 2981；`n²d` 乘加；4096 序列、32 层 32 头的 2.2×10¹² 次乘加；KV 缓存 2 GiB 与 GQA 512 MiB 的算式 |
| S3 | 模型输出是提案，程序才是合同 | 语法、模式、业务规则、证据四道门；`null` 与“未知”的区别；超时与幂等；4096 窗口减去输出与模板后的 3284 token 预算 |
| S4 | 八题全对，能说明什么 | 8/8 的 Wilson 区间约 `[0.68, 1.00]`；15/20 约 `[0.53, 0.89]`；配对 McNemar 3:0 的 p=0.25、5:0 的 p=0.0625、6:0 的 p=0.03125；10 个指标的多重比较约 40% 假阳性 |
| S5 | 回退能恢复文件，恢复不了世界 | 存活/就绪检查；代码、模型、索引、环境整包回退；清单哈希；外部副作用与补偿；RTO 要把重建索引算进去；陌生人复做 |

这些文章只使用课程已有算例、公开公式和本仓库可检查的记录；没有新增“某模型内部如何”的断言，也没有把统计示例写成实测成绩。

## 4. 插图

### 4.1 封面与阶段插画

`build-book-art.mjs` 生成 1 张封面和 5 张 480×640 阶段插画，全部为可编辑 SVG，`--check` 做字节比对。封面是 A5 比例（1240×1754），阶段插画共用同一套等轴薄板、松绿、沙色和细角标；每张插画只讲一个动作：

- S1：三张错开的纸页、一个只落在有原句那一格的勾、回到原文的虚线；
- S2：一个查询看向三个位置、权重线粗细分层、被遮住的未来；
- S3：请求—校验—回执三层节点，失败分支单独停下；
- S4：闭环里的基线、改动与复测，外面一圈浅色区间带；
- S5：封好的交付包、哈希封条、服务，以及退回上一个整包的弧线。

阶段插画不承担正文信息，正文和导言仍完整可读；图只做“门口”的视觉提示。

### 4.2 图解统一

新增 `figure-frame.mjs`：纸色、18 px 点阵纸纹、9 px 细边框、四角登记角标。所有生成的课程图解（学习图、应用图、故事图、机制图）改用同一纸面；10 张早期手绘图由 `build-static-frames.mjs` 注入同一纸面，不改标签和几何。边框在 9 px 处，正文图形从 15 px 以后开始，不挤压标签。

正文图注统一编号为 `图 C01-1`（答案版 `图 C01-A1`），编号由导出器按章生成，源 Markdown 仍写“图：……”。图号只在书里出现，网页保留原图注，避免两套编号。

## 5. 验证

本批可重复执行的检查：

```text
npm run build:llm
python scripts/llm/export_books.py
python scripts/llm/check_epub.py --jar <epubcheck.jar> --epub deliverables/llm-course.epub --report deliverables/llm-course-epubcheck.json
python scripts/llm/check_epub.py --jar <epubcheck.jar> --epub deliverables/llm-course-answers.epub --report deliverables/llm-course-answers-epubcheck.json
npm run check:course:llm
npm test
```

`check_course.py` 覆盖：

- `llm-course.json` 的源指纹、四个成品哈希与文件大小；
- 正文/答案 PDF 的 A5 尺寸、封面图、页数、书签数、30 章页码与书签一致、图号、两页目录的实际页码、页眉/页码样例、展示页页边遮盖；
- 正文 EPUB/答案 EPUB 的 cover-image、manifest、spine、nav、阶段/章入口、本地链接与锚点、PNG 签名；
- 两套 EPUBCheck 5.3.0 报告与当前 EPUB 哈希绑定，零 fatal/error/warning。

自动检查能证明结构、页码、边界和哈希，不证明版式好看、读者读得懂。真实初学者、独立复做、独立阅读器和读屏验收仍按 [ACCEPTANCE.md](ACCEPTANCE.md) 保留，不因本批通过而关闭。

## 6. 边界与未完成

- 本批没有真实读者试读数据；不能写“读者觉得更漂亮”或“更容易读”。
- 版式美感由设计规则和几何检查支撑，仍需要一次人工目视签核；本 spec 不把自动抽页当成审美结论。
- 深读文章是课程作者编写的解释，不是模型内部读数，也不是统计论文；公式与数字可复算，结论范围以文中限定为准。
- 阶段插画是构图提示，不替代阶段导言、章节正文和图注。
- 十二课手绘书继续用旧版式；本批只把 30 章课程书做成独立书版，避免改动已验收的 171 页成品。

## 7. 追加：术语、符号与能力门

书末再加一份工具页，解决“读了后面忘了前面”和“同一个字母在不同章指两件事”的问题：

- **术语表**：按 S1–S5 分 7 张表，收 60 余个正文反复使用且容易混淆的词；每条给最短解释和首次出现章节，不写成百科条目。
- **符号表**：固定 `x/X`、`q/k/v`、`d_k`、`n`、`T`、`p_i`、`L`、`η`、`KL`、`α`、`B/T/C`、`top_k` 等写法，并明确 `T` 在不同章分别指温度或序列长度。
- **能力门自检**：把 K1–K5 写成“最低证据 / 常见替代品（不算）”，例如“一次截图”不能替代 K3 的失败记录，“作者演示”不能替代 K5 的独立复做。

同时给正文二级标题加自动序号（`1.`、`2.`……），网页、PDF、EPUB 同源；答案页不加序号，避免和题目编号混淆。序号只帮助定位，不改变原文章节标题与锚点。

这份工具页在网页为 `glossary.html`，在书里排在深读之后；`check_course.py` 同时检查它的 PDF 书签、目录页码与 EPUB 导航。

## 8. 追加：全书地图

目录之后再加一张整页《全书地图》，把“三十章分散在五个阶段”变成一眼可读的结构：

- 五条水平阶段线，从 S1 到 S5；每条线上按章号放圆点，右侧菱形是能力门 K1–K5。
- 每条线左侧写阶段名与阶段产出，右侧能力门用同一套等轴标记；虚线表示阶段顺序。
- 图内只放章号，不塞章名；章名与摘要仍由目录、阶段页和章首页承担。
- SVG 源稿为 `book/assets/handdraw/llm/book-map.svg`，由 `build-book-art.mjs` 生成并 `--check` 比对；网页为 `map.html`，PDF/EPUB 为整页图 + 可见 h1 + 图注。
- 地图标题由 HTML 提供，图内不再重复大标题，避免网页 h1 与图内标题打架；图只保留顶部小字“五阶段 · 三十章 · 五道能力门”。

`check_course.py` 校验地图的 PDF 书签、目录页码与 EPUB 导航；地图不作为课程通过证据，只作为阅读路径。
