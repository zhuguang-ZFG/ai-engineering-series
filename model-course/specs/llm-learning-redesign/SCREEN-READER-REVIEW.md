## 已有的浏览器证据

`python scripts/llm/check_accessibility.py` 检查了 30 个真实 Chrome 可访问性树和 4 组键盘流程，课程网络请求为零。它覆盖控件名称、地标、中文语言、替代文本、ARIA 引用、跳过导航，以及以下交互：

- 连续训练的开始、暂停、步数上限和重置；焦点落在可继续操作的按钮上，状态区避免逐帧重复写入。
- 蒸馏滑块的方向键、数值及表格行标题。
- 非法 JSON 的输入焦点、`aria-invalid` 和关联错误文本；修改输入后清除过期错误状态。
- 检索证据链接展开来源，并将焦点移入来源内容。

这证明浏览器提供了相应语义和键盘行为，未证明屏幕阅读器已正确宣布它们。原报告保存在忽略的 `tmp/llm-review/accessibility-report.json`。
