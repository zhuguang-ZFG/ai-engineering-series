# 原书迭代 02：手绘图形与读图体验

> 本文保留迭代 02 的范围与证据；最新章节阅读检查见[迭代 03](original-book-readability-03.md)，任务入口见[当前计划](PLAN.md)。

本轮继续修改原《Vibe Coding 101》，保留 Stage 1–3、附录及原有 195 个章节名称和顺序。插图沿用 FA-040 极简手绘线稿、纸色与绿色标注，在原有点位替换，未另建教材。

## 画面改进

上一轮的流程图虽然文字清楚，仍有纵向列表过长、图形信息较少的问题；原需求漏斗和 JTBD 图宽达 1200 像素，小屏显示时标签偏小。本轮统一为 480×640 的 3:4 画幅，正文标签不小于 26 SVG 像素。轻微不规则轮廓、纸纹和绿色笔触保持手绘感，图内用短标签，较长的解释放在相邻正文与图注中。

| 原图 | 构图依据 | 改进 |
| --- | --- | --- |
| 学习路线 | IG-008 流程步骤 | 蛇形路径配八种工作图标，标出顺序及每步产出 |
| 排错 | IG-008 流程步骤 | 用报错界面、证据、补丁与复测画面串起四步；失败支路回到证据收集 |
| 部署 | IG-008 流程步骤 | 电脑、构建、平台、手机连成完整路线，图下分开代码回滚和数据恢复 |
| 数据库索引 | IG-004 对比 | 同一组八条记录对比扫描与范围定位，只突出查找编号 6 的路径 |

| JTBD | IG-002 中心标注 | 围绕真实可想象的“会后行动清单”，说明情境、结果和现有做法 |

图形通过确定性 SVG 生成，原图路径不变，可编辑且无外部字体或图片依赖。新版脚本会同步生成[手绘图集](../design/handdraw/book-figures.html)。阅读页中的手绘图支持点击或键盘打开原尺寸 SVG，禁用 JavaScript 时仍可使用。

## 相邻正文改进

需求筛选章节取消“定金转化率高于 10% 就证明需求真实”等固定结论，改为记录招募来源、样本、报价、周期、支付/退款和再次使用；示例故事及估算数字明确标为教学假设。收入公式区分可触达人群、付费假设和周期收入，不再把未扣成本的收入情景称作已验证市场规模。

同时修正“越细分越愿意付费”“身边有人就是天然理解用户”等说法。需求筛选增加“经历—假设—下一步行为”练习；JTBD 增加从导出按钮改写成任务描述的练习。图注指明阅读顺序、示意范围与可核验结果；Git 连线明确表示历史演进，避免与 Git 对象的父指针方向混淆。

## 实际验证

- 八张 SVG 实际渲染并逐张查看；文字无重叠和越界，标签最小 26px，在 320px 手机的 288px 正文栏约为 15.6px。
- 八张图分别在原章中按 375px 宽度截图，检查图注和实际显示；禁 JavaScript、离线状态下点图可打开原尺寸。
- 图集在 320、768、1440px 三种宽度检查。
- 原书 198 个页面、594 组窗口/字号布局检查；本地资源和目录链接核对。最终计数见[本轮证据](evidence/original-book-illustration-02.json)。
- `npm test` 完整通过，36 项单元测试通过；构建一致性、配套电子书指纹和仓库验证通过。配套 PDF/EPUB 本轮无需重新导出，其内容与生成输入未改动。

复核：`npm run build:book`、`npm run check:figures:book`、`npm run check:reading:book`、`npm test`。原始截图与日志在忽略目录 `tmp/illustration-polish-02/`；正式预览位于 `design/handdraw/renders/`。本轮覆盖八张图和对应内容，不将其表述为全书所有插图均已重绘。
