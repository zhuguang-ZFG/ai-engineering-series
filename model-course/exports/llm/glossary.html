五阶段学习路线旧实验与回查

术语、符号与能力门

这一页不是背单词。术语表只收正文反复使用、且容易混淆的词；每条给出最短解释和首次出现的章节。符号表固定同一套写法，避免同一个字母在不同章指两件事。最后一节把五道能力门写成可检查的证据，而不是“读完即可”的口号。

遇到不熟的词，先回到它首次出现的章节看例子，再回来看这条解释。术语解释不能代替正文里的条件、数字和失败对照。

S1 会使用

术语 最短解释 章节
原文 材料里逐字出现的句子；核对时最好连标点一起保留 C01
转述 用自己的话重说，可以帮忙阅读，但不能冒充原文 C01
结论 你的判断；可能对也可能错，必须能回到原文检查 C01
任务约定 材料、字段、缺失规则、输出格式、交付对象和完成标准的合称 C02
证据位置 能定位到具体文档、版本和字符范围的引用，不是一段可被重复出现的字符串 C01、C14
未知 材料没有提供，不能用常识补全的状态 C01
冲突 两份材料给出不同说法，尚未确认哪份现行有效 C01、C03
可核对性 另一个陌生人能否在有限步骤内找到支持结论的原句 C01、C04

S2 懂原理

术语 最短解释 章节
token 分词器切出的片段；可以是一个词、半个词、标点，甚至部分 UTF-8 字节 C05
词表 ID token 在词表中的存储编号；编号大小不表示词义远近 C05、C06
logit 模型对候选给出的未归一化分数，可正可负，不相加为 1 C05
softmax 把一组分数变成非负、总和为 1 的份额；分数差越大，分布越尖 C05
温度 采样前对分数做缩放的参数；低温更集中，高温更分散，但不补事实 C05
向量 一串数字；本章用它表示 token 的初始查表值或上下文后的表示 C06
余弦相似度 两个向量夹角的余弦；只看方向，不看长度，且要用完整维度计算 C06
Q / K / V 同一行输入经过三组不同投影得到的查询、键、值 C07
因果掩码 在 softmax 之前把未来位置的分数设为负无穷，使其权重为 0 C07
注意力权重 对 V 的混合比例，按行相加为 1；不是事实置信度 C07
残差 把子层输入原样加回输出，保留一条信息通路 C08
前馈层 对每个位置独立作用的两层线性变换加非线性 C08
交叉熵 用目标概率给预测概率算的损失；目标概率越低，罚分越大 C09
梯度 损失对参数的局部斜率；更新时沿负方向走一小步 C09
学习率 每次更新走多远；太大会越过，太小会走不动 C09
预训练 用大量文本学习“下一个 token”的通用目标 C10
指令微调 用示范数据教模型按任务形式作答 C10
偏好优化 用回答比较信号调整行为；不保证每条事实正确 C10

S3 能实现

术语 最短解释 章节
HTTP 状态码 服务端对请求的分类结果；401、404、500 指向不同的失败层 C12
超时 客户端在限定时间内没收到回执；不等于服务端没有执行 C12、C16
未知状态 既不能确认成功、也不能确认失败的状态；必须先查状态再重试 C12、C16
片段 从文档切出的可检索单元；应带稳定 ID、版本、哈希和字符位置 C14
版本 文档的某次发布；更新后旧片段的结论可能过期 C14
权限 谁可以读哪份材料；检索前就要检查，不能等回答完再补 C14、C17
词项检索 按字词匹配取回片段；对同义改写不敏感 C15
embedding 检索 用向量相似度取回片段；可能把“词像”但“事不对”的段落排前 C15
top-k 取回片段的数量；多不等于证据充分 C15
工具调用 模型提出请求，由应用校验、程序执行、回执返回的链路 C16
回执 工具执行后的结果与终态；没有回执就不能汇报完成 C16
幂等 同一个请求重复执行，结果与执行一次相同；重试前要有这个约定 C16
引用校验 检查引用是否存在、是否支持结论、是否来自当前版本 C17

S4 会改进

术语 最短解释 章节
冻结评测 改动前固定材料、题目、判据和预算，之后用同一把尺子比较 C18
开发 / 验证 / 保留 开发集用于改，验证集用于选，保留集最后独立评估 C18
检索失败 正确片段没有被取回，或取回了错误版本 C19
生成失败 片段在上下文里，模型却选错、漏掉或改写 C19
引用失败 回答写了引用，但引用不支持该结论或已过期 C19
上下文窗口 本次调用最多能放多少 token；不是长期记忆，也不是参数容量 C20
KV 缓存 推理时缓存每层 K 和 V，避免重复计算；大小随层数、头数、序列长度增长 C20
外部记忆 存在模型之外、需要检索或读取的材料；不会自动进入本次输入 C20
Agent 让模型根据中间结果决定下一步的架构；必须有边界、权限和停止条件 C21
分位数 把延迟或费用排序后取 50%、90%、99% 位置的值；平均值会掩盖长尾 C22
张量 带形状的多维数组；[B, T, C] 分别表示批次、序列和通道 C23
自动微分 由计算图反向求梯度，不靠手写每个参数的导数 C23
decoder 按因果顺序读入并生成下一个 token 的模型结构 C24
全量 SFT 用示范数据更新全部参数；改变面大，成本也大 C25
LoRA 冻结底座，只训练低秩适配矩阵；改变面小，但仍需数据和评测 C25
蒸馏 用教师的分布、分数或回答训练学生；不是复制教师权重 C26
软标签 教师对多个候选的概率分布；比只给正确答案多出类间关系 C26
KL 散度 衡量两个分布的差异；方向不同，惩罚的重点也不同 C26

S5 独立交付

术语 最短解释 章节
OCR 从图像中识别文字；结果要保留图像哈希、区域和原文回看 C27
文本层 PDF 里可直接提取的文字；扫描件可能没有文本层 C27
多模态 同时处理文字、图像、音频等输入；能看图不等于能核对像素来源 C27
最小系统 满足任务与约束的最少组件；不是组件越多越专业 C28
存活检查 进程还在吗；通常只返回 200，不代表能接真实请求 C29
就绪检查 模型、索引、权限、依赖都可用吗；要能解释失败在哪一层 C29
发布包 代码、模型、索引、配置、环境和运行手册的整包 C29
清单哈希 发布包内每个文件的 SHA-256；启动前逐项校验，不匹配就拒绝启动 C29
回退 切回上一个可用整包；能恢复文件，恢复不了已发生的外部副作用 C29
陌生项目 没有演示过、材料与任务都需自己确认的项目；不能照抄案例改标题 C30
独立复做 另一个人只凭发布包、README、冻结题目和判据，从零走完并留下记录 C30

五阶段能力门自检

能力门不是“读完”，而是“留下可检查的证据”。下面列出最低证据和常见替代品；替代品不能算通过。这张表只帮助自检，不替代 分层验收 里的真人、独立复做与读屏条件。

门 最低证据 常见替代品（不算）
K1 会使用 一份陌生通知的报告：每格有原文位置或“材料未提供”，冲突单列，另一个人能复找 一段通顺总结、只有结论没有原句、把常识补进表
K2 懂原理 手算一组注意力权重与输出，说明形状；完成一次参数更新并解释损失变化 只背公式、只看图、把示意值当模型内部读数
K3 能实现 干净环境跑通资料助手：正常、缺失、冲突、无命中、越权、服务失败各有记录 一次截图、预置成功答案、只跑 happy path
K4 会改进 冻结题与判据；单变量对照；训练/重载/留出证据；失败与开销报告 只报平均分、改题后对比、把损失下降当能力提升
