# 内部评审预算（教师专用）

本文档只对教师读者开放，用于演示检索前的权限过滤；学生读者不应看到本文内容。

## 2026 年第四季度评审

本季度安排三次课程评审，评审人共 3 名。场地与设备费用合计 1200 元，评审劳务合计 1800 元，材料印制 300 元，预留机动 900 元。总预算 4200 元。

## 报销规则

评审结束后 10 个工作日内提交票据和签到表。超过预算的项目需要提前书面说明，不得先支出后补批。机动费用只能用于场地延期、设备替换和临时增加的评审材料，不能转为劳务。

## 记录保存

预算表、审批邮件和报销凭证保存两年。涉及个人账号的信息只在财务系统中保留，不写入公开课程材料。
