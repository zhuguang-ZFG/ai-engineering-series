# 冷读评审台账（经典级五维）

> 口径来自 SPEC §9.2：每张图按 **趣味可读 / 生动形象 / 简单易懂 / 过目不忘 / 由浅入深** 打 1–5 分，任一维 <4 即回炉，返工项在此逐条销账。
> 打分方式：不带写作上下文，只看 `design/handdraw/renders/hd-*.png` 栅格图 + 正文相邻段落，问「这张图替读者省了哪一段重读」。
> 路径一律用仓库相对路径（`scripts/validate.mjs` 会扫机器绝对路径）。

## 评分维度怎么判（避免自说自话）

| 维度 | 判定动作 |
| --- | --- |
| 趣味可读 | 能否指出图里那**一个具体比喻或场景钩子**（小黑板 / 时光机 / 翻译官…） |
| 生动形象 | 遮住 70% 文字后，图形层是否仍讲得清主干结构 |
| 简单易懂 | 单图新概念 ≤5；figcaption 一句话说清「省了什么」；无未解释术语 |
| 过目不忘 | 原文口诀或数字锚是否**画进了图里**而不是只留在正文 |
| 由浅入深 | 图在该节的位置是否符合认知梯度（先给地图，再给细节） |

## 本轮流程侧发现（值得固化的坑）

- `render_figures.py` 首版用 `\b(width|height)` 解析 `<svg>` 尺寸，`stroke-width="4"` 里的 `width` 被当成属性，取到 4×88 的窗口，Chrome 出一张 112 字节的空白 PNG 且**退出码为 0**。修法：只在 `<svg …>` 开标签内匹配，并要求属性名前不连字符；脚本再加「PNG < 5000 字节即失败」的硬检查。教训：**栅格化后必须真的看图，不能只看命令成功**。
- 图与相邻图片的正文间隔要在插入**之后**再量一次：本轮六张插入后最小间隔 4502 字（要求 ≥400–500）。审计脚本要排除 figure 自身块，否则会把 `<figure>` 当成「上一张图」得出 0 间隔的假阳性。
- **并行 agent 会各自发明颜色**。15 张图里 5 种越界色、19 处 accent 小字，全是不同 agent 独立收敛出的“看起来差不多”的值——靠评审抓不完。已把校验前移到出图环节：`render_figures.py` 渲之前用 `tokens.css` 做白名单，并对 `<text fill="#1f883d|#e2601f">` 直接非零退出（已用探针验证会拦）。下一批 agent 的提示词里不必再复述色值，改成「渲不过就报错」。
- 门本身也要被验：`contrast.mjs` 静默零输出跑了整个 Phase A。以后新增校验脚本，先**故意塞一个坏例子确认它会失败**，再信它的绿色。

- **点位是评分维度之一，不是 agent 说了算**。`git-history` 的图本身合格，但 agent 选的章首位置会让一张 5 簇收口图变成劝退图。第三批起，插入位置由主会话按「这个位置读者已经认识几个概念」重判，agent 只报锚点唯一性，不报位置建议的裁决权。
- **一张图只留一个收口元素**。`cache-layers` 首稿的横幅+药丸是 agent 想同时强调两句原文，结果两句都不响。已固化为 R-06 的规则；下一批 agent 提示词里直接写「底部只允许一条 banner，多余结论进 figcaption」。
