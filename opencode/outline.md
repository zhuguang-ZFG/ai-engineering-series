# OpenCode：从原理到实战：目录与实验计划

状态：提纲，章节题名可随实验调整。每行是后续写作任务，不表示该章已经完成。[分册入口](README.md)。

| 章 | 主题 | 要回答的问题 | 实验或可交付证据 |
| --- | --- | --- | --- |
| 1 | 安装与第一项任务 | CLI、工作目录和模型配置分别在哪里生效？ | 记录版本，在临时仓库运行一次只读任务。 |
| 2 | 从终端到服务端 | TUI、HTTP/事件流和会话服务如何连接？ | 画出请求与流式结果两条路径。 |
| 3 | 配置与项目身份 | 全局、项目、工作树设置怎样合并？ | 构造配置冲突并记录最终值。 |
| 4 | 会话、消息与持久化 | 中断、恢复、分支与文件状态有何区别？ | 恢复同一会话，比较日志和磁盘。 |
| 5 | 模型接口与流式响应 | 模型切换会改变哪些请求与事件？ | 用本地记录替身观察请求结构。 |
| 6 | 工具注册与执行 | schema、执行器、输出截断分别在哪一层？ | 自定义只读工具，制造取消与输出过长。 |
| 7 | 权限与审批 | 工具调用何时进入权限判断？ | 在临时目录比较允许、拒绝和询问。 |
| 8 | 插件 Hook：从返回对象到实际调用 | V1 Hook 怎样修改输出，怎样处理失败与清理？ | 运行 review-trace 处理器实验；已有样章。 |
| 9 | 插件加载、状态与 V1/V2 | 发现、初始化、重载和 V2 Scope 的边界是什么？ | 已写样章；Windows 宿主四场景通过，V2 仍为源码观察。 |
| 10 | MCP 与外部工具 | 远程协议和本地插件在哪一层相遇？ | 启动临时本地 MCP 服务，观察断线。 |
| 11 | LSP、搜索与代码上下文 | 工具检索与自动上下文怎样分工？ | 比较有/无语言服务时的证据。 |
| 12 | Agent 配置与任务委派 | 配置、模型和权限是否由子任务继承？ | 用受控任务记录父子会话关系。 |
| 13 | 工作树、快照和撤销 | 会话恢复是否等于撤销文件修改？ | 隔离工作树做修改、失败与恢复。 |
| 14 | SDK、API 与自动化 | 怎样从外部控制一次任务？ | 最小客户端创建会话、消费事件、取消。 |
| 15 | 调试与可观察性 | 重复调用、卡住与错误如何定位？ | 按日志关联调用 ID，注入失败。 |
| 16 | 插件发布与兼容升级 | 如何升级而不把新版文档混入旧接口？ | 用同一契约样例比较两个固定版本。 |
| 17 | 完整项目实战 | 从需求、修改、测试到交付怎样串起来？ | 修复一个带失败测试的小仓库。 |
| 18 | 架构取舍与迁移 | 哪些能力可替换，哪些依赖宿主？ | 与 Pi、Omp 按同一组问题比较。 |

附录 A：固定版本与源码导航。附录 B：配置和命令速查。附录 C：实验复现与未验证项。附录 D：术语、来源和跨册对照。

写作顺序以实验依赖为准，章节不以固定字数填充。安装、加载、生命周期、状态、权限和失败都必须有对应的源码或实验依据。
