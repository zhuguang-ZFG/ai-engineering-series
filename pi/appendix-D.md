# 附录 D 术语表

本表按本书用法给一句话定义；与上游文档冲突时，以上游钉版为准。

| 术语 | 一句话 | 章节 |
| --- | --- | --- |
| **agent** | 模型 + 工具 + 循环组成的程序；本书的主角 | 第 1 章、第 9 章、第 10 章 |
| **harness** | 组织模型、工具、循环的那层程序；"车" | 第 1 章、第 25 章 |
| **provider** | 提供模型访问的服务/账号，负责鉴权与请求格式 | 第 3 章 |
| **模型（model）** | 真正生成回复的东西，有 ID、上下文、能力标记 | 第 1 章、第 3 章、第 10 章 |
| **凭据（credential）** | provider 认你的方式：OAuth、API key、云凭据 | 第 3 章、第 22 章 |
| **turn** | 一条助手回复 + 它产生的工具调用与结果 | 第 9 章、第 12 章 |
| **run** | 由一次输入触发的一段执行，可含多个 turn 与重试 | 第 9 章 |
| **steering** | 跑动中发送、在当前 turn 后生效的消息（`Enter`） | 第 4 章、第 9 章 |
| **follow-up** | 跑动中发送、在整个 run 后生效的消息（`Alt+Enter`） | 第 4 章、第 9 章 |
| **abort** | 中止当前 run，排队消息回到编辑器（`Escape`） | 第 4 章、第 9 章 |
| **tool call** | 模型要求执行某个工具的结构化输出 | 第 11 章 |
| **tool result** | 工具执行后回喂给模型的内容 | 第 11 章 |
| **活动分支** | 从当前叶到根的那条路径；模型只看到它 | 第 5 章、第 12 章 |
| **会话（session）** | 一棵持久化的条目树，存成 JSONL | 第 5 章、第 12 章 |
| **叶（leaf）** | 当前所在的条目；决定活动分支 | 第 5 章、第 12 章 |
| **压缩（compaction）** | 把旧消息摘要掉，用 `compaction` 条目替换上下文 | 第 7 章、第 12 章 |
| **分支摘要** | 离开一条分支时生成的摘要，附到新分支 | 第 7 章 |
| **上下文窗口** | 模型一次请求能接收的 token 上限 | 第 7 章、第 10 章 |
| **token** | 模型计费与上下文的基本单位 | 第 10 章 |
| **系统提示** | 每次请求都带的指令，分 `preamble`/`tools`/`rules` 等段 | 第 6 章 |
| **上下文文件** | `AGENTS.md` / `CLAUDE.md`，进 `project_context` | 第 6 章 |
| **项目信任** | 是否加载项目设置/扩展等资源；不是沙箱 | 第 22 章 |
| **扩展（extension）** | 进程内 TypeScript 模块，可注册工具/命令/事件 | 第 14 章、第 15 章 |
| **技能（skill）** | 带 `SKILL.md` 的指令包，描述常驻、全文按需读 | 第 16 章 |
| **提示模板** | Markdown 文件，文件名即 `/` 命令 | 第 17 章 |
| **Pi 包** | 用 npm/git 分发的扩展+技能+模板+主题集合 | 第 18 章 |
| **print 模式** | 跑一次、把最终文本写 stdout、退出 | 第 8 章、第 21 章 |
| **JSON 模式** | 跑一次、把事件写成 JSONL | 第 8 章、第 21 章 |
| **RPC 模式** | 常驻子进程，stdin 命令 / stdout 响应与事件 | 第 8 章、第 19 章 |
| **SDK** | 把 agent 嵌进 Node/Bun 进程的 TypeScript 接口 | 第 19 章 |
| **codemode** | 在 QuickJS 沙箱里跑脚本、调用工具/分类/图像模型 | 第 11 章 |
| **MCP** | Model Context Protocol，外部工具/资源的协议 | 第 14 章、第 22 章 |
| **classifier 模型** | 不聊天，回答是/否、多选或打分的模型 | 第 10 章 |
| **钉版（pin）** | 本书写作所依据的 release tag 与完整提交 | 第 1 章、第 25 章 |
| **漂移** | 上游版本变化导致书中结论失效 | 第 25 章 |
| **未验证** | 本书没有实跑、只按文档描述的结论 | 第 20 章 |
