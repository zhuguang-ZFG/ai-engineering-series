# 海岬观测站设备手册（节选）

本手册面向值班员，只包含日常检查与故障上报所需的最小信息。拆机、改线和固件升级必须由维护组执行。

## 电池组 BT-24

BT-24 为可充电磷酸铁锂电池组，标称容量 24 安时。充满后，常规记录模式可连续工作约 36 小时。环境温度低于 0 摄氏度时，可用容量会下降，手册不承诺具体比例，应以当日实测放电曲线为准。

充电使用随箱的 29.2 伏恒压充电器。充电区必须保持通风，禁止在电池组旁存放易燃物。发现外壳鼓包、渗液或异常发热时，立即断开充电并上报维护组。

## 校准

风速传感器建议每 180 天校准一次。校准由维护组完成，值班员只负责在设备台账中登记日期和证书编号。超过 180 天未校准的数据要标注“未校准”，不能直接当作正式观测值。

雨量计每 90 天清理一次滤网。清理后先做一次空翻试验，确认翻斗计数正常再接入记录。

## 故障代码

- E01：供电电压低于 11 伏。检查充电状态和接线，不要自行提高充电电压。
- E03：风速传感器无脉冲。先检查线缆接头，再上报维护组。
- E07：存储卡写入失败。停止采集并更换已格式化的存储卡，保留旧卡用于分析。

故障代码只表示设备自检结果，不等同于故障原因。维修记录需要写明代码、发生时间、现场处理和复核结果。
