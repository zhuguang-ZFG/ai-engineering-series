# C07 作业核对：注意力到底计算了什么

题目在 [C07 正文](../lessons/c07.md)，容差 ±0.002。按“分数—softmax—加权”顺序给值。

## 一、两个缩放后分数

- `q·k1 = 1×1 + 1×0 = 1`
- `q·k2 = 1×0 + 1×3 = 3`
- `√d_k = √2 ≈ 1.4142`
- 缩放后：`1/1.4142 ≈ 0.7071`，`3/1.4142 ≈ 2.1213`

## 二、softmax 权重

- `exp(0.7071) ≈ 2.0281`
- `exp(2.1213) ≈ 8.3421`
- 总和 `≈ 10.3703`
- 权重：`[2.0281/10.3703, 8.3421/10.3703] ≈ [0.1956, 0.8044]`

两权重相加为 1。第二个位置分数更高，权重更大，但第一个位置仍保留约 19.6% 的贡献。

## 三、加权输出

`0.1956×[1,2] + 0.8044×[3,0] = [0.1956+2.4133, 0.3911+0] ≈ [2.6089, 0.3911]`

第一维主要来自 V2 的 3，第二维只来自 V1 的 2。

## 四、未来的 k3/V3 改动

输出**不变**。位置 0 和 1 看不见位置 2；它的分数在 softmax 前被设为负无穷，权重为 0。即把 V3 改成 `[5,5]` 甚至 `[100,-100]`，乘 0 后都不贡献。这正是因果掩码要保证的：训练时不能靠未来 token 预测当前目标。

若站在最后一个位置，未来为空，改前面的 V 就会改变输出；边界是“不能看自己后面”，不是“只能看固定两个位置”。

## 五、形状

- `X`：4×3；`WQ`：3×2 → `Q`：4×2（K、V 同理）。
- `QKᵀ`：(4×2)·(2×4) → 4×4。行是查询位置，列是被看位置。
- mask 后逐行 softmax → 权重 4×4，每行和为 1。
- 权重 (4×4) 乘 `V` (4×2) → 输出 4×2。

## 六、先 mask 再 softmax

先 softmax 再 mask，未来位置已经分到非零权重；把它们置零后，该行权重和小于 1，输出被整体缩小，且相当于偷偷改变了归一化。先 mask 成负无穷再 softmax，未来位置的 `exp` 为 0，可见位置重新归一化到和为 1，输出才是“只在可见集合内做加权平均”。两者在数值和语义上都不同。

## 七、评分要点

- 两个缩放分数正确：2 分。
- softmax 的 exp、总和、权重齐全且落在容差内：3 分。
- 加权输出正确：2 分。
- 未来改动判断“不变”并给出权重为 0 的理由：2 分。
- 四个形状正确：3 分。
- 先 mask/后 mask 的归一化差异说清：2 分。

关键失败：mask 用 0 分；把权重当事实置信度；形状转置弄反；输出只写权重不乘 V。
