# C06 作业核对：一串数字怎样表示文字

题目在 [C06 正文](../lessons/c06.md)，容差 ±0.001。以下按“点积—长度—余弦”的顺序给值。

## 一、`[1,2,2]` 与 `[2,1,0]`

- 点积：`1×2 + 2×1 + 2×0 = 2+2+0 = 4`
- `‖a‖ = √(1+4+4) = √9 = 3`
- `‖b‖ = √(4+1+0) = √5 ≈ 2.2361`
- 余弦：`4/(3×2.2361) = 4/6.7082 ≈ 0.5963`

方向有相当夹角，不是“几乎相同”。

## 二、`[1,1,0]` 与 `[1,1,2]`

- 点积：`1+1+0 = 2`
- `‖a‖ = √2 ≈ 1.4142`
- `‖b‖ = √6 ≈ 2.4495`
- 余弦：`2/(1.4142×2.4495) ≈ 2/3.4641 ≈ 0.5774`

二维影子只取前两维 `[1,1]` 与 `[1,1]`，所以画出来重合；第三维从 0 变成 2，参与点积与长度，余弦因此明显小于 1。这就是“投影会藏掉维度”。

## 三、`[0,3,0]` 与 `[0,5,0]`

- 点积：`0+15+0=15`
- 长度：3 与 5
- 余弦：`15/(3×5)=1`

余弦为 1，表示同向；但数组不同（长度不同），不能写成“同一个向量”。若关心大小而非方向，要看长度或距离，不能只看余弦。

## 四、零向量

`[0,0,0]` 的长度为 0，余弦公式分母为 0，结果**未定义**。不能写 0：0 会被读成“完全无关”，而零向量根本没有方向。程序中应显式返回“未定义/不适用”，并避免拿它参与排序。

## 五、两句话的解释

- **ID 接近不能推出语义接近**：ID 只是词表存储位置；语义关系来自训练后的向量与上下文计算，编号顺序没有语义约束。42 与 43 可以毫无关系。
- **上下文表示接近也只是线索**：它说明在这组向量与这次比较中方向接近，不代表事实正确、同义或可互换；还要看任务、日期、权限与原句。

## 六、评分要点

- 第 1 题点积、长度、余弦齐全且落在容差内：3 分。
- 第 2 题指出影子只取前两维、第三维参与计算：2 分。
- 第 3 题区分“同向”与“同一数组”：2 分。
- 第 4 题写“未定义”，并解释为什么不是 0：2 分。
- 第 5 题两句都提到“编号/表示只是线索，不是事实保证”：1 分。

关键失败：把余弦当概率；把二维重合当同一向量；用零向量算相似并参与排序。
