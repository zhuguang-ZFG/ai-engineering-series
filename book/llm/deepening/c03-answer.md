# C03 作业核对：看似合理为什么仍可能错

题目在 [C03 正文](../lessons/c03.md)。材料：通知 A（周六14:00，需提前报名）、C（改到周日14:00）、D（11月5日发布，报名延至11月10日）。下面是核对表与判分要点。

## 一、四项主张的检查

| 主张 | 原句 | 三道检查 | 判定 |
|---|---|---|---|
| 周六14:00 | A“读书会周六14:00开始” | 来源存在；原句在；但 C 说改到周日 | **冲突**（A 与 C 并列，待确认生效版本） |
| 城市图书馆 | 无 | 没有原句 | **缺失/无依据** |
| 免费参加 | 无 | 没有原句 | **无依据** |
| 报名截止11月10日 | D“报名截止延长至11月10日” | 来源存在；原句在；日期晚于 A | **有依据（现行）**，但需记明这是延期后的日期 |

若把“周日14:00”单列一行，它的原句是 C，判定可以是“有依据”，前提是确认 C 是同一活动的有效补充通知。更稳妥的写法是两行并列：

- A：周六14:00（原始通知，日期较早）
- C：周日14:00（写明“改到”，需确认发布者与生效范围）

“报名截止11月10日”与开头那句“已于11月7日截止”不同：后者若引用 A 或旧版，就属于**过期**；若没有任何文件写 11月7日，则属于**无依据**。两种判定都要求你指出具体来源，不能笼统说“错了”。

## 二、存在但不支持的引用

“城市图书馆”若被贴上 B 的“地点：社区阅览室”，就是典型：B 确实存在，句子也真，但它写的是阅览室，不支持图书馆。另一种更隐蔽：贴“参与者需提前报名”，这句话真实，却不含地点，也不含截止日期。

判定标准不是“有没有引用”，而是“引用中的主语、时间、地点、条件、否定词是否与主张一致”。只要有一项相反或不相关，就不能标“有依据”。

## 三、需要补材料的一项

“免费参加”没有任何来源。要下结论，需要找：活动通知的完整版、报名页面的费用说明，或发布方的补充公告。问题应写成“向谁确认哪一项”，例如“向读书会发布方确认是否收费，索取含费用条款的通知或报名页截图”，而不是“再查一下”。

“3—5号楼”式的范围歧义如果出现在本题材料里，也应列为待确认，不能自行解释。

## 四、两行并列的写法

| 时间说法 | 原句 | 来源/日期 | 状态 |
|---|---|---|---|
| 周六14:00 | “读书会周六14:00开始” | 通知 A，较早 | 旧说法，待确认是否被替代 |
| 周日14:00 | “活动改到周日14:00” | 通知 C | 新说法，待确认发布者与生效范围 |

两行并列不是“两个答案都对”，而是把冲突保留到有人能裁决为止。报告中可以写“当前无法确定唯一时间，需向发布方确认”，这属于合格交付。

## 五、可交付但仍待确认的状态说明

示例：

> 状态：待补充。已确认：报名截止延长至11月10日（D）。冲突：时间为周六（A）或周日（C），需确认 C 的生效范围。缺失：地点与费用无材料支持。未执行：未报名、未联系发布方。

这句话同时说明了已确认、冲突、缺失和未做事项。它比“已完成”更可信，因为接手的人知道下一步该做什么。

## 六、评分要点

- 四项主张齐全，且每项有判定：4 分。
- 正确识别“A 与 C 冲突”，没有二选一硬拼：3 分。
- 正确识别“真引用但不支持”的例子并说明理由：3 分。
- 把旧截止日判为过期或无依据，并指出缺失的具体文件：2 分。
- 待确认项写成可执行动作：2 分。
- 状态说明包含“未做事项”，没有冒充已报名或已确认：2 分。

关键失败：把“已仔细核对”当证据；把冲突写成未知而丢掉两条原句；把 D 的日期贴到 A 的句子上。
