# C26 答案与核算：蒸馏学到的是什么

## 1. 两个温度的 softmax

教师分数 `[3,2,0]`。

`T=1`：

```text
exp(3)=20.0855, exp(2)=7.3891, exp(0)=1
sum=28.4746
p(1)=[20.0855, 7.3891, 1]/28.4746
    ≈[0.7054, 0.2595, 0.0351]
    ≈[70.54%, 25.95%, 3.51%]
```

`T=2`：

```text
exp(1.5)=4.4817, exp(1)=2.7183, exp(0)=1
sum=8.2000
p(2)=[4.4817, 2.7183, 1]/8.2000
    ≈[0.5465, 0.3315, 0.1220]
    ≈[54.65%, 33.15%, 12.20%]
```

温度升高后，最高项从约 70.54% 降到 54.65%，最低项从 3.51% 升到 12.20%。它没有增加新事实，只把原来的分数差压平，让低概率候选也参与训练。教师和学生必须用同一个 T；训练温度与部署采样温度分开设置。

## 2. KL、软目标与 T²

```text
KL(p(T) || q(T)) = Σ_i p_i(T) ln[p_i(T) / q_i(T)]
```

方向是教师在前、学生在后。教师固定时，`KL(p||q)` 与软目标交叉熵只差一个不随学生参数变化的常数，所以对学生梯度相同；交换成 `KL(q||p)` 不是同一个算法。

混合损失：

```text
L = α T² KL(p(T)||q(T)) + (1-α) CE(y, q(1))
```

默认 `α=0.7, T=2`，学生初始三个 logits 都是 0，所以 `q(T)=q(1)=[1/3,1/3,1/3]`。可以核对数量级：

```text
KL(p(2)||uniform) ≈ 0.1457
软项 = 0.7 × 4 × 0.1457 ≈ 0.4080
硬项 CE(水, uniform) = -ln(1/3) ≈ 1.0986
硬项加权 = 0.3 × 1.0986 ≈ 0.3296
L ≈ 0.4080 + 0.3296 = 0.7376 ≈ 0.7378（四舍五入差异）
```

T² 是尺度补偿：未补偿的软目标梯度约含 `1/T`，在固定分数差等近似下概率差还会再小约 `1/T`，合起来接近 `1/T²`。它不是准确率乘 T²，也不保证不同温度下梯度完全相等。

## 3. 混合梯度与一步更新

```text
∂L/∂s_i = α T (q_i(T) - p_i(T)) + (1-α)(q_i(1) - y_i)
```

正确教师 `[3,2,0]`、`p(2)=[0.5465,0.3315,0.1220]`、学生 uniform：

```text
软项 = 1.4 × ([1/3,1/3,1/3] - [0.5465,0.3315,0.1220])
     ≈ [-0.2985, 0.0026, 0.2959]
硬项 = 0.3 × ([1/3,1/3,1/3] - [1,0,0])
     = [-0.2, 0.1, 0.1]
总梯度 ≈ [-0.4985, 0.1026, 0.3959]
```

学习率 `0.4`：

```text
s_new = [0,0,0] - 0.4 × [-0.4985, 0.1026, 0.3959]
      ≈ [0.1994, -0.0410, -0.1584]
```

教师 `[3,2,0]` 不动；变化的是学生。X09 的混合损失约 `0.7378`，与上面的数量级一致。

## 4. 错误教师：为什么水的概率会下降

保持 `α=0.7, T=2, lr=0.4`，把教师换成 `[0,3,2]`。

教师 `p(2)`：

```text
softmax([0,1.5,1]) ≈ [0.1220, 0.5465, 0.3315]
```

学生初始 `q=[1/3,1/3,1/3]`。梯度：

```text
水: 1.4×(0.3333-0.1220) + 0.3×(0.3333-1)
   ≈ 0.2959 - 0.2 = 0.0959
茶: 1.4×(0.3333-0.5465) + 0.3×(0.3333-0)
   ≈ -0.2985 + 0.1 = -0.1985
咖啡: 1.4×(0.3333-0.3315) + 0.3×(0.3333-0)
     ≈ 0.0026 + 0.1 = 0.1026
```

更新：

```text
水:   0 - 0.4×0.0959 ≈ -0.0384
茶:   0 - 0.4×(-0.1985) ≈ +0.0794
咖啡: 0 - 0.4×0.1026 ≈ -0.0410
新 logits ≈ [-0.0384, 0.0794, -0.0410]
softmax 后水的概率 ≈ 32.03%
```

水的概率从 33.33% 降到约 32.03%，因为错误教师的软信号把学生往“茶第一”拉，而硬标签只占 0.3。这个例子说明：**更像教师**不等于**更接近事实**。把 `α` 调到 0，学生只按硬标签学习；这是对照，不是宣布 `α=0` 永远最优。KL 很小也只说明分布像教师；教师稳定地错，学生也可能稳定地学像。

## 5. 只有教师文本时

拿不到完整 logits/概率时，能用的目标是教师示范序列的负对数似然：

```text
L_text = -Σ_t ln q_学生(ŷ_t | x, ŷ_<t)
```

`ŷ_<t` 是示范中已经写在前面的 token；训练时把它作为前缀，让学生预测下一个示范 token，这叫 teacher forcing。你拿不到：

- 教师在整个词表上的完整分布；
- 教师未选中候选的概率；
- 教师内部权重或不可见推理状态。

你能拿到的是被教师选中并写出的序列。若教师的 tokenizer 与学生不同，要按学生的分词器重新编码；不能按下标硬减两个不同词表的分布。还要筛选错误答案、缺失条件、矛盾解释和重复样本，保留来源与错误类型。

## 6. 与 SFT/RL/量化/剪枝/RAG 的区别

| 方法 | 改什么 | 与蒸馏的关系 |
| --- | --- | --- |
| SFT | 用示范更新参数 | 教师响应可作为 SFT 数据；来源与目标分开 |
| RL | 按奖励优化策略 | 可与蒸馏组合，但蒸馏不等于 RL |
| 量化 | 数值精度 | 不改“向谁学”；可对蒸馏后学生再做 |
| 剪枝 | 删除/稀疏化结构 | 结构机制不同，可与蒸馏组合 |
| RAG | 取回材料放进输入 | 通常不改参数；不能替代数据更新与引用 |

DeepSeek-R1 首版报告第 2.4 节的 Qwen/Llama 学生配方，只属于那个版本的公开描述；不能推广到所有蒸馏，也不能移给 V4.1 Flash 或 Kimi K3。

## 7. 本课能声称与不能声称

能声称：

- 在 X09 的三个候选教学分布上，按给定公式和默认设置，软/硬混合损失、梯度、一步更新和错误教师方向可复算；
- 本课微型 decoder 的 SFT/LoRA 是真实的参数更新与冻结对照（若运行了 `adapt` 并保留输出）；
- 本课的 masked response、group-disjoint 留出和 reload 检查是真实代码行为。

不能声称：

- 调用过真实教师模型或采集过教师 logits/文本；
- 本目录 `sft.jsonl` 是教师输出（它是作者编写的示范）；
- 三个候选的 toy 分布代表商用模型内部概率；
- 学生“更像教师”就等于事实正确或通用能力提升；
- 某个 rank/α/T 在所有任务上最优。

## 8. K4 阶段门参考要点

以下是自检要点，不是替你做题的“标准答案”。

**第 1 题（闭卷解释）**：目标错位是 `inputs=full[:-1]`、`targets=full[1:]`；因果掩码在 softmax 前把严格上三角置 `-inf`；正弦位置无参数、按 `max_len`/`C` 重算；残差保证子层输出加回 `[B,T,C]`，pre-norm 在子层前归一化；软目标、KL、T²、混合梯度公式必须方向正确。通过标准是能说清“为什么”，不是背符号。

**第 2 题（小 decoder 证据）**：`inspect` 看 `parameters`、`architecture.positions`、`future_invisibility`；`train` 看 `losses.{train,val,test}`、`target_shift.aligned`、`future_invisibility.bitwise_equal`、`reload.bitwise_equal`、`sample.generated_text`；`sample` 看 `hit_eos`、`positions_used`。必须报告留出损失，不能只报训练损失；不能把玩具结果说成通用能力。

**第 3 题（SFT/LoRA）**：全量 SFT 可训练 69,760，底座哈希变化、`base_frozen=false`；LoRA 可训练 6,600，底座哈希不变、`base_frozen=true`、`base_grads_all_none=true`、`lora_changed=true`；两者 `reload.bitwise_equal` 都应为真。留出 `delta` 以实际运行输出为准；不预设赢家。

**第 4 题（错误教师）**：公式 `αT(q-p)+(1-α)(q-y)`；方向是 `KL(p||q)`；默认 `α=.7,T=2,lr=.4`；水概率从 33.33% 降到约 32.03%；解释软信号压过硬标签。不能把教师错误当成事实，也不能把 25.95% 当成“杯中有茶”的概率。

**第 5 题（单变量）**：只改一个因素。例：去掉 `masked_fill` 后 `future_invisibility.bitwise_equal=false`；或把 LoRA rank 从 4 改 8，可训练参数从 6,600 变 13,200；或改温度，看分布变化。必须记录改动前后字段、命令和条件；说明这个实验不能证明什么。

阶段门要求的是可复核证据，不是“看起来完成了”。没有真实运行的地方写“未验证”，不要用文字补成已完成。
