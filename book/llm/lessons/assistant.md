# 会续写为什么还要学听指令？

你问“把通知里的时间提取出来”，希望得到时间，而不是让对方接着编一份通知。会预测后续文字，与稳定地完成对话任务之间，还隔着训练目标和数据的选择。

## 三种训练信号，各自在教什么

## 预训练：从大量序列里学预测

常见自回归语言模型先用大量序列学习后续 token 的分布。要把预测做好，参数可能学到语言结构、知识联系和其他规律。训练数据有范围、质量和时间限制，不能称作“读完了全部人类资料”。

模型也可能记住部分训练内容，但生成回答不等于逐条查询一个经过核验的原文库。

## 指令微调：用示范教任务

监督式指令微调（SFT）提供任务、上下文与示范回答，继续通过训练更新参数。例如任务是提取时间，示范就只输出“周六14:00”。

聊天模板则告诉程序消息属于 system、user 还是 assistant，以及边界在哪里。把文本放进模板是组织本次输入；用示范数据微调是更新参数。这两个动作不能互相替代。

## 偏好优化：让回答符合选定标准

同一个问题有几个回答时，可以用比较、奖励等信号调整行为。标准可能包括遵循要求、有帮助、依据充分等。偏好数据和评价方式也会有局限。

InstructGPT 展示了先用示范监督微调，再用回答排序训练奖励模型、做强化学习的路线。DPO 使用偏好数据构造另一种优化目标；它与使用奖励模型的 PPO 路线不能当作同一个算法。实际模型还可能采用其他训练方法。

“说得礼貌”与“说得有依据”要分别检查。上面的两个回答里，“城市图书馆”听起来很自然，却没有材料支持。经过偏好训练，也不代表每条回答都正确。

## 换成实际模型试一次

用本课下方的同一任务，分别试 DeepSeek V4.1 Flash 和 Kimi K3。先保存它们第一次的回答，再要求“指出每项的依据原句”。检查有没有把未知地点补成一个熟悉的场所。

如果回答不同，先看输入材料、消息角色、思考或联网等模式是否一致。不能仅凭两个回答反推出各自的训练配方，也不能把一次成功写成准确率结论。

## 再深一层

在自回归 SFT 的常见实现里，仍然通过示范回答中目标 token 的负对数概率计算损失；训练哪些位置、数据怎样混合，由具体实现决定。偏好优化使用不同信号和目标。“对齐”描述行为更符合选定要求，不是一种事实核验保证。
