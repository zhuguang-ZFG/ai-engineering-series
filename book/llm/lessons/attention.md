# 模型怎样利用前文？

读到“我把苹果切开”的“把”时，后面的“苹果”和“切开”还没有出现。一个从左向右生成文字的模型，在这个位置能用到哪些信息？

先选择第二个位置“把”，看可见范围。再把未来位置的 V 改大，检查当前输出有没有变化。

## 先算匹配，再汇总内容

注意力里有三组向量：Q 参与查询，K 用于匹配，V 提供汇总的内容。通常它们由当前位置表示经过学到的投影得到。本实验直接给出小矩阵，让计算能逐项看清。

选中“把”后，程序先用它的 Q 分别与“我”和“把”的 K 求点积，再除以维度平方根。softmax 把可见分数变成权重。最后按权重加总各位置的 V，得到一个新的向量。

这不是从句子里挑一个词当答案。几个位置都可以贡献内容，V 的各个数值都参加加权。实验中的百分比表示这一层、这一头的汇总权重，不能直接解释为模型认定某句话是真的概率。

## 遮住未来，避免偷看目标

当前位置之后的分数在 softmax 之前被屏蔽。公式常把这些位置写成负无穷，指数为零；页面用“屏蔽”显示。可见位置的权重和为 1，未来位置的权重为 0。

在“把”的位置，只改“苹果”和“切开”的 V，当前汇总不会变。移到最后一个位置时，已经没有未来位置，修改按钮也就停用。这是在检验因果性。

训练时也要遵守这个约束。虽然一整段已知文本可以并行计算很多位置，每个位置仍不能用后面的目标 token 来预测它自己。

## 一个注意力头还不能解释整个模型

真实网络会把多个头的结果组合起来，还包括前馈层、残差连接、归一化等计算。位置信息让网络能够利用顺序；如果完全抹掉顺序，单靠一组词很难分清“甲帮助乙”和“乙帮助甲”。

展开课末的“深入图”，可以看到一种明确的 pre-norm 简化块：先归一化再进子层，子层输出与原路径相加；同样的结构再经过前馈子层。位置的加入方式、归一化方式和注意力结构都有不同实现，不能把这张图当作所有模型的架构图。

注意力权重也不是完整的思考记录。我们没有取得 DeepSeek V4.1 Flash 或 Kimi K3 的内部 Q/K/V，页面上的矩阵不能归给它们。

## 用到提问里

整理通知时，把需要比较的原句放进当前可见材料，清楚注明 A、B 两个版本。材料没有进入输入，模型就无法通过这次注意力计算使用它；进入了输入，也仍然需要检查回答是否准确采用了证据。

## 再深一层

本实验是 `Attention(Q,K,V) = softmax(mask(QKᵀ / √d)) V`，其中 `d = 2`。选第二个位置，第一分量等于 `权重[我] × 1 + 权重[把] × 0`，第二分量等于 `权重[我] × 0 + 权重[把] × 2`。你可以对照页面的小数自己复算，显示时的四舍五入会带来少量误差。
