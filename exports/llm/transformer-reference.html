Transformer 与注意力机制原理

2017 年的 Transformer 论文提出了一种主要依靠注意力、前馈层、残差连接和归一化的序列转换架构。原始论文是机器翻译的编码器—解码器模型；后来许多语言模型采用其中的解码器路线，也有模型采用编码器或编码器—解码器。不能把论文中的完整结构直接说成所有大模型的唯一结构。

先跟着“已知前文，预测下一个 token”看注意力，再分清原始结构与常见的 decoder-only 路线。图和数字是课程示意，不是 DeepSeek V4.1 Flash、Kimi K3 或其他商用模型的内部读数。

一、RNN 的困境与 Transformer 的突破

RNN 按时间步处理序列，每一步把隐藏状态传给下一步。这种顺序依赖限制了训练时同一条序列内的并行；长距离依赖和梯度传播也会增加训练难度。它们是 RNN 的常见限制，不等于每个 RNN 任务都会失败。

1.1 RNN 的三大致命缺陷

“无法并行”“一定遗忘”“必然梯度爆炸”都说得太绝对。更准确的说法是：循环计算带来顺序依赖，长序列会让信息和梯度传播更难，工程实现需要通过门控、截断或其他方法处理这些问题。应把具体模型、长度和训练设置写出来，再比较结果。

1.2 Transformer 的革命性突破

自注意力让一个位置用 Query 与一组 Key 匹配，再汇总对应的 Value。训练时可以把已知的多个位置打包成矩阵计算；自回归生成仍然要按步追加新 token。并行计算是训练路径的性质，不代表回答会一次产生整段文本。

二、Transformer 完整架构：从整体到细节

“完整架构”在本节专指原始论文的 encoder-decoder 设计。编码器把输入序列变成连续表示，解码器在因果掩码下逐步生成输出，并可通过交叉注意力读取编码器表示。decoder-only 语言模型省略编码器和交叉注意力，直接在一串前缀上预测下一个 token。

2.1 编码器（Encoder）

原始编码器每层包含多头自注意力和逐位置前馈网络，外加残差连接与层归一化。现代实现可能采用 pre-norm、不同激活函数、位置表示或其他层结构；“6 层、512 维”是原论文配置，不能当成当前模型的通用规格。

前馈层在各位置使用相同参数，做非线性变换；原论文写作 FFN(x)=max(0,xW₁+b₁)W₂+b₂。残差把子层输入与输出相加，归一化调整单个位置的特征尺度，帮助训练深层网络，但不保证训练一定稳定。原论文是 LayerNorm(x+Sublayer(x)) 的 post-norm；课程深入图采用 x+Sublayer(Norm(x)) 的 pre-norm 示意，两种顺序不能混写。

2.2 注意力的计算过程

对某个位置，先算 QKᵀ / √d_k，再对可见位置做 softmax，最后用权重汇总 V：

Attention(Q, K, V) = softmax(QKᵀ / √d_k + M)V

M 在可见处加 0，在屏蔽处加负无穷。decoder-only 教学例里，输入位置 i 可以看自己及更早位置，用来预测 i 后的 token；不能看未来目标。训练时输入与预测目标错开一位，这才避免把答案提前给模型。注意力输出只是网络中的一个子层，注意力权重不能单独当作完整解释。

三、Query、Key、Value：注意力的三剑客

Q、K、V 是由隐藏表示经过不同线性投影得到的向量。把 Q 说成“正在提问”、K 说成“标签”、V 说成“内容”有助于入门，但这些是功能类比，不是模型里存着三张人能直接读懂的表。

3.1 三个向量的角色

Q 与 K 的匹配决定权重，V 参与加权汇总。Q/K 的相似度高，不代表 V 的内容一定与人类语义相似；投影矩阵和后续层共同决定表示。自注意力里的 Q、K、V 可以来自同一序列，交叉注意力则让一侧的 Q 读取另一侧的 K/V。

3.2 注意力计算公式

公式中的 d_k 是 Key 的维度，缩放用于控制点积的数值范围。softmax 的每一行权重和为 1（忽略被屏蔽的位置）；这是一种归一化，不是事实概率，也不是模型对“重要性”的最终评分。

四、多头注意力：从多个角度理解语义

多头注意力把同一输入投影到几个较小的子空间，各头独立计算注意力，再拼接输出并用 W^O 混合。不同头可能学到不同的依赖，也可能有重叠；不能预先给某个头贴上“语法头”或“情感头”的固定标签。

4.1 多头的工作机制

head_i = Attention(QW_i^Q, KW_i^K, VW_i^V)
MultiHead(Q,K,V) = Concat(head_1, …, head_h)W^O

在本地的双头练习中，输入是三个二维向量，两个头各投影成一维，位置 2 只能看前两个位置。程序实际算出两头的权重和输出，再拼接、乘以 W^O。这能展示矩阵关系，但没有训练、位置编码、残差、归一化或完整 Transformer 层。

人工输入 X=[[1,0],[0,1],[1,1]]，当前为第 2 个位置。各头投影矩阵见同源 fixture；本例两头 d_k=1，缩放因子为 1。

本地计算 第 1 头 第 2 头
掩码后权重 [0.500000, 0.500000, 0.000000] [0.268941, 0.731059, 0.000000]
加权 V 输出 [0.500000] [0.731059]

拼接结果为 [0.500000, 0.731059]，经过人工输出矩阵后得到 [1.231059, -0.231059]。表中数值由源码计算后保留六位小数。

在行向量约定下，拼接 [a,b] 乘 W^O=[[1,1],[1,-1]] 得 [a+b,a-b]。改掉输出投影矩阵，最终结果也应变化；把未来第三行改得很大，第二位置的输出仍应不变。记录按第 1、2、3 位置称呼，源码索引从 0 开始。

4.2 多头的优势

多头提供了多个可学习的投影空间，并行计算这些头通常便于实现。原论文基础配置用 8 个头、每头较小维度；头数和维度是配置，不是固定标准。并行不等于免费，计算时间还受矩阵形状、内存和硬件影响，也不能保证多头天然更鲁棒。效果要在给定数据、参数和评估任务上比较。

五、Transformer 完整架构：编码器与解码器

原始 encoder-decoder 结构与 decoder-only 结构要分开讲。前者适合输入序列到输出序列的转换，后者把任务表示成“给定前缀预测下一个 token”。两者都可以使用注意力、前馈层和位置表示，但掩码和信息流不同。

5.1 编码器（Encoder）

编码器的自注意力通常允许输入位置互相读取（具体掩码按任务而定）。它输出每个输入位置的表示，供解码器的交叉注意力读取，或交给分类、检索等任务的后续层。

5.2 解码器（Decoder）

解码器的自注意力使用因果掩码，位置 i 不能读取未来目标。原始 encoder-decoder 解码器还包含对编码器输出的交叉注意力；decoder-only 模型没有这条编码器到解码器的支路。生成时，已经给出的前缀可以并行做一次处理，新增 token 仍按时间步继续。

5.3 现代变体：仅编码器 vs 仅解码器

路线 常见用途 关键边界
仅编码器 表示、分类、抽取 不是天然的逐 token 自回归生成器
仅解码器 续写、对话、代码生成 因果掩码限制当前位置读取未来
编码器—解码器 翻译、摘要、序列转换 解码器可通过交叉注意力读取输入表示

名称只是架构路线，不能仅凭名字推断某个具体产品的训练数据、工具能力或性能。课程的生成主线使用 decoder-only 作为常见示例。

六、位置编码：告诉模型词的顺序

没有位置机制或随位置变化的掩码时，自注意力对输入行的重排呈相应重排，难以单凭这一步区分词序。因果掩码本身已引入“可见前缀”的顺序约束，不能笼统说所有注意力完全不知道顺序。位置表示进一步提供位置关系，可加到嵌入，也可进入分数或 Q/K。

6.1 位置编码的必要性

“我爱你”和“你爱我”包含相同词但顺序不同。位置机制让模型在计算时区分这些位置；它不等于给每个 token 附加一个人能直接解释的“第几维坐标”。

6.2 正弦余弦位置编码

原始 Transformer 使用正弦和余弦函数：

PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

这是原论文的一种固定方案。它提供确定的数值模式，但“每个位置都有唯一编码”和“可以无条件外推任意长度”都需要限定维度、长度和实现，不能直接当成普遍保证。

6.3 现代位置编码方案

可学习位置嵌入给位置配置可训练向量；相对位置方法用位置差参与计算；RoPE 通过旋转 Q/K 使注意力分数带有相对位置关系；ALiBi 在注意力分数上加入与距离有关的偏置。这些方案不都把位置向量直接加到输入。长上下文表现仍取决于训练长度、扩展方法和实现；采用 RoPE 不自动支持任意长度。

七、Transformer 的影响与未来

Transformer 已被用于文本、视觉、语音和其他序列任务，但跨模态系统常包含额外的编码器、投影层或连接模块。使用 Transformer 这一名称，不能推出产品一定支持图像、音频、工具或联网。

7.1 统一的预训练范式

预训练和后续适配是常见路线之一。自回归语言模型可用下一个 token 目标训练；编码器模型、序列到序列模型和多模态模型的目标可以不同。参数规模大不自动等于事实可靠或任务适配。

7.2 跨模态的通用架构

视觉 Transformer、语音模型和多模态语言模型都可能使用注意力，但输入如何变成 token、模态怎样对齐、输出是什么，需要看具体论文和版本。这里不把 GPT-4、Whisper 或 AlphaFold 的内部实现简化成同一张结构图；它们的公开资料支持范围也不同。

7.3 大模型时代的基石

Transformer 的矩阵运算适合现代加速器，推动了更大规模的训练和推理。规模扩展可能带来能力变化，但能力是否出现、如何测量，取决于任务和评估设计；“足够大就自动涌现”不是可复现的通用定律。旧稿“GPT-4 万亿参数”没有该技术报告支持；报告明确未公开模型规模等细节，不能补成确定数字。

7.4 未来的挑战与方向

标准全注意力在序列长度为 N 时，注意力分数矩阵的长度项通常呈 N²；实际内存和时间还受头数、维度、批量、硬件和实现影响。FlashAttention 通过分块和 IO-aware 实现减少 GPU 内存读写，仍计算精确注意力，不能把它说成把算法复杂度普遍变成线性。稀疏注意力、线性注意力和滑动窗口是不同取舍，也不能互相当作同义词。

可解释性也有边界：注意力权重只描述一个子层的加权关系，不能单独证明模型的完整因果理由。长上下文、位置外推、多模态对齐和能耗都需要针对版本与任务测试。

八、总结

Transformer 提供了一个由注意力、前馈层、残差、归一化和位置处理组成的可堆叠架构。原始论文是编码器—解码器；现代语言模型常取 decoder-only 路线。读者先分清架构、训练和推理，再用 Q/K/V、掩码和多头小矩阵追踪一次计算，最后按具体模型资料判断窗口、模态、工具和性能。

想看单头因果注意力，先做 L04 实验；想看多头投影、拼接和输出投影，运行仓库根目录的 node book/llm/examples/multihead.mjs。这两个练习都使用人工矩阵，不读取 DeepSeek V4.1 Flash 或 Kimi K3 的内部状态。
