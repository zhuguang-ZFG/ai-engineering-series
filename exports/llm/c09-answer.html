C09 作业核对：训练为什么能改变预测

题目在 C09 正文，容差 ±0.002。按“更新前—梯度—更新后”顺序给值。

一、更新前的概率

分数 [1,0]：

  • exp(1)=2.71828，exp(0)=1
  • 总和 3.71828
  • 概率 [0.7311, 0.2689]

目标第一个，更新前损失 −ln(0.7311)≈0.3133。

二、梯度与更新

softmax 交叉熵梯度 = 预测概率 − 目标指示值：

  • 第一个：0.7311 − 1 = −0.2689
  • 第二个：0.2689 − 0 = 0.2689

学习率 0.5：

  • 新分数：1 − 0.5×(−0.2689) = 1.1345；0 − 0.5×0.2689 = −0.1345

三、更新后的概率与损失

  • exp(1.1345)≈3.1095，exp(−0.1345)≈0.8742
  • 总和 ≈3.9837
  • 概率 [0.7806, 0.2194]
  • 损失 −ln(0.7806)≈0.2477

损失从约 0.3133 降到约 0.2477，下降了。目标候选概率上升，另一个下降，符合“朝降低损失的方向走一步”。

四、链式法则

∂L/∂w = (∂L/∂s)×h = (−0.4)×2 = −0.8

更新：w = 1.5 − 0.1×(−0.8) = 1.58。负梯度意味着增大 w 会降低损失，所以减去负数等于加上 0.08。

五、序列目标

序列“A B C”：

位置 输入 目标
0 A B
1 A B C
2 A B C 无下一个

最后一个位置没有下一个 token，常见处理是：不计算该位置损失，或在序列末尾加结束符 EOS 作为目标。不能拿 C 预测 C 自己，也不能让位置 2 看到未来。

六、损失降但提取错地点

三句话即可：

  1. 训练损失衡量的是这批材料上的下一个 token 预测，不是“通知字段提取正确率”。
  2. 模型可能学到材料里的偶然线索（例如“活动”后总跟某个地点词），换一份通知就失效。
  3. 训练目标或材料本身可能错；损失下降只会让模型更熟悉这些目标，不会自动核验事实。

还可以补：训练集与留出集若来自同一批模板，分数会虚高；任务层要另设字段级检查。

七、评分要点

  • 更新前概率正确：2 分。
  • 两个梯度正确：2 分。
  • 更新后分数、概率、损失正确且说明下降：4 分。
  • 链式法则与更新值正确：2 分。
  • 目标错位表正确，最后位置处理合理：2 分。
  • 三句话分别覆盖“指标不同、虚假线索、目标/材料可能错”：3 分。

关键失败：用当前位置预测自己；把训练损失当任务准确率；学习率符号弄反；把一次更新说成“模型学会了”。
