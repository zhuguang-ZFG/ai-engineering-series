C10 核对：从续写到助手（K2）

题目在 C10 正文。先独立完成四问，再对照本页。所有容差 ±0.002；只写结果不通过，必须能指出公式或中间值。

K2 不取平均：A、B、C 的每个数值都在容差内，D 四项分类全对，才算通过。

A. softmax 与温度

T=1，分数 [2,1,0]：

  • exp(2)=7.38906，exp(1)=2.71828，exp(0)=1
  • 总和 11.10734
  • 概率 [0.66524, 0.24473, 0.09003]

T=0.5，分数除以 0.5 得 [4,2,0]：

  • exp(4)=54.59815，exp(2)=7.38906，exp(0)=1
  • 总和 62.98721
  • 概率 [0.86681, 0.11731, 0.01588]

温度降低，分布更尖；最高分候选从约 0.665 升到约 0.867。概率仍相加为 1，且不表示事实正确。

B. 一行注意力

缩放后分数：

  • q·k1 = 0×2 + 1×0 = 0
  • q·k2 = 0×0 + 1×2 = 2
  • 除以 √2≈1.4142：[0, 1.4142]

softmax：

  • exp(0)=1
  • exp(1.4142)≈4.11325
  • 总和 5.11325
  • 权重 [0.19557, 0.80443]

加权输出：

0.19557×[1,1] + 0.80443×[2,0] = [0.19557+1.60886, 0.19557] ≈ [1.80443, 0.19557]

未来位置被遮住，权重为 0；若把未来的 V 改得很大，输出不变。

C. 一步更新

更新前：

  • softmax([0,0]) = [0.5,0.5]
  • 目标第一个，损失 −ln(0.5)≈0.6931

梯度（预测 − 目标）：

  • 第一个：0.5−1=−0.5
  • 第二个：0.5−0=0.5

学习率 0.8：

  • 新分数：0−0.8×(−0.5)=0.4；0−0.8×0.5=−0.4

更新后：

  • exp(0.4)=1.49182，exp(−0.4)=0.67032
  • 总和 2.16214
  • 概率 [0.68997, 0.31003]
  • 损失 −ln(0.68997)≈0.3711

损失从约 0.693 降到约 0.371；目标候选概率上升，另一个下降。方向正确，但这是一次更新、一个训练对，不等于模型学会任务。

D. 四种变化的分类

  1. 加入 system 提示：输入变化（上下文）。改的是本次请求内容；参数不变；通常只影响本次或使用同一提示的请求。
  2. 200 条示范做监督微调：参数变化。改的是权重；保存检查点后持续；需要独立评测确认是否改善。
  3. 温度 0.2→0.9：解码设置。改的是采样分布；参数与输入内容都不变；只影响生成方式。
  4. 编辑保存的偏好备注：外部状态。改的是应用保存的数据；下一次请求可能把它作为输入带上；参数不变；权限与适用范围仍要检查。

四个答案都要说明“改了什么/是否持久”，只写类别不够。

E. 常见错误

  • 把 softmax 的 exp 值当概率（未归一化）。
  • 注意力计算忘记除以 √d_k，或先 softmax 再 mask。
  • 梯度符号写反，导致目标概率下降还说“损失降低”。
  • 把温度当“事实可靠性旋钮”。
  • 把“加 system 提示”说成参数更新，或把“微调”说成只改本次输入。
  • 从产品行为反推训练配方。

F. 评分与验证状态

  • A：两组 exp、总和、概率齐全且全部在容差内。
  • B：分数、权重、输出齐全，并说明 mask 使未来权重为 0。
  • C：梯度、新分数、新概率、新损失齐全，且说明损失下降方向。
  • D：四项分类与“是否持久”全对。
  • 方法：公式可见，未跳步。
